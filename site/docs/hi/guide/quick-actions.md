# त्वरित क्रियाएँ

उन लोगों के लिए जो समूह के किसी एडमिन फ़ोन या दूसरे एडमिन कंप्यूटर से किसी कंप्यूटर को लॉक, स्लीप, रीस्टार्ट, शटडाउन करना या उस पर कोई तय प्रोग्राम चलाना चाहते हैं।

कोई **एडमिन** एक टैप या एक कमांड से त्वरित क्रिया चलाता है, और लक्ष्य कंप्यूटर उसे तभी चलाता है जब उस कंप्यूटर के अपने उपयोगकर्ता ने उस क्रिया को स्थानीय रूप से चालू किया हो। हर त्वरित क्रिया डिफ़ॉल्ट रूप से बंद रहती है, और कोई भी किसी क्रिया को दूर से चालू नहीं कर सकता।

## अंतर्निहित क्रियाएँ

| क्रिया | यह क्या करती है | समर्थित डिवाइस |
|---|---|---|
| `lock` | स्क्रीन लॉक करती है | कंप्यूटर, छोटे डिवाइस |
| `sleep` | कंप्यूटर को स्लीप में डालती है | कंप्यूटर, छोटे डिवाइस |
| `reboot` | 1 मिनट की चेतावनी के बाद कंप्यूटर को रीस्टार्ट करती है | कंप्यूटर, छोटे डिवाइस |
| `shutdown` | 1 मिनट की चेतावनी के बाद कंप्यूटर को शटडाउन करती है | कंप्यूटर, छोटे डिवाइस |
| `cancel-shutdown` | लंबित रीबूट या शटडाउन रद्द करती है | कंप्यूटर, छोटे डिवाइस |
| `restart` | Connect Beyond Borders सेवा को रीस्टार्ट करती है | कंप्यूटर, छोटे डिवाइस |
| `keyboard-layout` | कंप्यूटर के [ब्लूटूथ कीबोर्ड](keyboards-and-tvs.md) का सक्रिय लेआउट अगले लेआउट पर बदलती है | ब्लूटूथ कीबोर्ड चालू वाले Linux कंप्यूटर |

`reboot` या `shutdown` से पहले 1 मिनट की देरी कंप्यूटर पर बैठे किसी भी व्यक्ति को अपना काम सहेजने या `cancel-shutdown` चलाने का समय देती है। Windows पर, साइन-इन किए हुए उपयोगकर्ताओं को सिस्टम चेतावनी भी दिखती है।

macOS और Windows पर, सत्र क्रियाएँ (`lock`, `sleep`, और कस्टम क्रियाएँ) साइन-इन किए हुए उपयोगकर्ता के क्लिपबोर्ड एजेंट के ज़रिए चलती हैं, इसलिए किसी का साइन-इन होना ज़रूरी है। macOS पर, `lock` के लिए ज़रूरी है कि **System Settings > Lock Screen > Require password after screen saver begins or display is turned off** को **Immediately** पर सेट किया जाए।

## 1. कोई अंतर्निहित क्रिया चालू करें

लक्ष्य कंप्यूटर पर ये कमांड चलाएँ (Linux, macOS और FreeBSD पर `sudo` इस्तेमाल करें; Windows पर बिना `sudo` के व्यवस्थापक टर्मिनल इस्तेमाल करें):

1. सभी क्रियाओं की सूची देखें और देखें कि हर एक को चलाने की अनुमति किसे है:

   ```sh
   cbb action
   ```

2. कोई क्रिया चालू करें:

   ```sh
   sudo cbb action enable lock
   ```

   पढ़ें कि यह क्रिया क्या अनुमति देती है और `yes` टाइप करें (या स्क्रिप्ट में `-yes` पास करें)।

   **परिणाम:** यह क्रिया आपके समूह के हर एडमिन के लिए चालू हो जाती है। Linux पर, Connect Beyond Borders `/etc/polkit-1/rules.d/60-cbb.rules` लिखता है जो सेवा को केवल चालू की गई क्रियाओं के लिए ज़रूरी polkit अधिकार देता है।

3. चाहें तो यह सीमित करें कि कौन-से एडमिन कोई क्रिया चला सकते हैं:
   - `-by` के साथ हस्ताक्षरकर्ता के प्रकार के अनुसार सीमित करें (मुख्य डिवाइस के लिए `root`, एडमिन फ़ोनों के लिए `phone`, एडमिन कंप्यूटरों के लिए `computer`, घड़ी हस्ताक्षरकर्ता के लिए `watch`):

     ```sh
     sudo cbb action enable reboot -by root,phone
     ```

   - डिफ़ॉल्ट रूप से, `reboot` और `shutdown` केवल उन एडमिन को स्वीकार करते हैं जिनकी कुंजियाँ हार्डवेयर में हैं (फ़ोन, Secure Enclave वाला Mac, या TPM 2.0 वाला PC)। फ़ाइल कुंजियों वाले एडमिन को भी अनुमति देने के लिए `-any-key` जोड़ें:

     ```sh
     sudo cbb action enable reboot -any-key
     ```

किसी एक क्रिया को फिर से बंद करने के लिए:

```sh
sudo cbb action disable lock
```

**परिणाम:** क्रिया तुरंत बंद हो जाती है। Linux पर, बंद करने से polkit नियम अपडेट या हट जाता है ताकि अप्रयुक्त अधिकार वापस ले लिए जाएँ।

## 2. अपनी खुद की क्रिया जोड़ें

आप हर कंप्यूटर पर अधिकतम 32 कस्टम क्रियाएँ तय कर सकते हैं (नाम 1 से 32 छोटे अंग्रेज़ी अक्षरों, अंकों या हाइफ़न के होने चाहिए, और अक्षर से शुरू होने चाहिए)।

1. लक्ष्य कंप्यूटर पर कमांड पंजीकृत करें, `--` के बाद प्रोग्राम का पूरा पाथ देते हुए:

   ```sh
   sudo cbb action add backup -by phone -- /usr/local/bin/backup.sh --quick
   ```

2. पढ़ें कि यह क्रिया क्या अनुमति देती है और `yes` टाइप करें।

**परिणाम:** Connect Beyond Borders इस कमांड को आपकी उपयोगकर्ता सेटिंग्स (`own-actions.json`) में सहेजता है ताकि केवल साइन-इन उपयोगकर्ता का एजेंट बिना शेल के ठीक वही प्रोग्राम और आर्ग्युमेंट सूची चला सके। भेजने वाले को केवल निकास स्थिति (exit status) मिलती है। कमांड को 15 सेकंड के भीतर पूरा होना चाहिए; लंबे कामों को बैकग्राउंड में शुरू करें।

किसी कस्टम क्रिया को हटाने के लिए:

```sh
sudo cbb action remove backup
```

## 3. किसी एडमिन से क्रिया चलाएँ

- **एडमिन कंप्यूटर (टर्मिनल) से:**

  ```sh
  cbb action -on DEVICE NAME
  ```

  `DEVICE` की जगह `cbb status` से लक्ष्य का नाम या डिवाइस ID लिखें, और `NAME` की जगह क्रिया का नाम।

  **परिणाम:** `cbb` बताता है कि क्रिया चली या लक्ष्य ने उसे क्यों अस्वीकार किया।

- **एडमिन फ़ोन से:**
  1. **CBB** खोलें और **होम** पर ऑनलाइन लक्ष्य कंप्यूटर को टैप करें।
  2. **त्वरित क्रियाएँ** के नीचे, वह क्रिया टैप करें जिसे आप चलाना चाहते हैं।
  3. अपने चेहरे, फ़िंगरप्रिंट, पासकोड, या (Aurora OS पर) अपने एडमिन PIN से पुष्टि करें। `reboot` और `shutdown` दूसरी बार भी पुष्टि माँगते हैं।

  **परिणाम:** लक्ष्य क्रिया चलाता है और फ़ोन **हो गया।** दिखाता है।

## 4. सभी क्रियाएँ बंद करें

- **लक्ष्य कंप्यूटर पर स्थानीय रूप से:**

  ```sh
  sudo cbb action off
  ```

- **किसी भी एडमिन कंप्यूटर से दूर से:**

  ```sh
  sudo cbb action off -on DEVICE     # one computer
  sudo cbb action off -all           # every computer in the group
  ```

- **एडमिन फ़ोन से दूर से:** **होम** पर डिवाइस पेज खोलें और **सब बंद करें** टैप करें।

**परिणाम:** प्रभावित कंप्यूटरों पर हर त्वरित क्रिया तुरंत बंद हो जाती है। केवल हर कंप्यूटर का अपना उपयोगकर्ता ही उन्हें स्थानीय रूप से फिर से चालू कर सकता है।

हर लक्ष्य कंप्यूटर अंतिम 100 क्रिया अनुरोधों का एक ऑडिट लॉग (`actions-log.json`) रखता है, जिसमें दर्ज होता है कि किसने कौन-सी क्रिया कब माँगी। सटीक सीमाओं के लिए देखें [सीमाएँ और अवधियाँ](../reference/limits.md#remote-paste-and-quick-actions)।
