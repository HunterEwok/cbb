# Без приложения

Для всех, кто хочет создать группу Connect Beyond Borders и управлять ею только с компьютеров, без
приложения на телефоне. На этой странице вы создадите группу на одном компьютере, добавите другие
компьютеры в домашней сети, настроите второго администратора и подключите компьютеры из другой сети по
SSH или через VPN.

![Компьютер с Linux держит группу и добавляет Mac и Windows по шестизначному коду](../images/without-app.svg)

Компьютер, который создаёт группу, становится её **главным устройством** (в утилитах командной строки оно называется *root*). [Установка Linux без прав root](install.md#without-sudo-rootless)
никогда не может быть главным устройством или администратором, а контейнеру Docker требуется
переменная окружения `CBB_KEYS_IN_FILE=yes`, прежде чем хранить ключи группы.

## 1. Создайте группу на компьютере

Выберите компьютер, который регулярно включён (Linux, macOS, Windows или FreeBSD), и
[установите Connect Beyond Borders](install.md).

1. Выполните на этом компьютере (в Windows опустите `sudo` в терминале от имени администратора или
   нажмите **Создать группу** в приложении для Mac либо в приложении в трее):

   ```sh
   sudo cbb new
   ```

2. Сохраните **лист восстановления**, который появится на экране — четыре строки букв и цифр плюс
   QR-код. Напечатайте или перепишите его и храните отдельно от ваших устройств.

**Результат:** этот компьютер становится главным устройством группы. На Mac с чипом Apple или T2 и на
ПК с Linux или Windows с TPM 2.0 его ключи хранятся в защищённом оборудовании; иначе они хранятся в
защищённых файлах (`cbb keys` начинается с `files`; см. [Ключи и аттестация](keys.md)). Копию листа
восстановления не хранит никто — это единственный способ перенести группу, если этот компьютер будет
потерян.

## 2. Добавьте компьютеры в домашней сети

Установите Connect Beyond Borders на каждый дополнительный компьютер в той же домашней сети, а затем
выполните сопряжение:

1. На главном устройстве (или любом компьютере-администраторе) откройте окно сопряжения:

   ```sh
   sudo cbb pair
   ```

   **Результат:** терминал выведет 6-значный код сопряжения и QR-код и будет ждать 5 минут. Окно
   сопряжения также можно открыть кнопкой **+** в приложении для Mac или приложении в трее.

2. На новом компьютере вступите в группу:
   - **Терминал:** выполните `sudo cbb pair -code` (в Windows опустите `sudo` в терминале от имени
     администратора) и введите 6 цифр по запросу.
   - **Приложение для компьютера:** откройте **CBB**, выберите **Вступить в группу** и введите 6 цифр.

   Каждый неверный код тратит одну из 3 попыток; окно закрывается после 3 неудачных попыток или сразу,
   как только устройство вступит в группу.

**Результат:** оба компьютера подтвердят вступление, и ваши буферы обмена начнут синхронизироваться
автоматически. Скопируйте текст на одном компьютере и вставьте на другом, чтобы проверить (см.
[Быстрый старт: скопируйте на одном, вставьте на другом](quickstart.md#4-copy-on-one-paste-on-another)).

## 3. Добавьте второго администратора и берегите лист восстановления

Назначьте второй компьютер **администратором**, чтобы можно было добавлять и удалять устройства, даже
когда главное устройство не в сети. Учтите, что компьютер можно сделать администратором, только если
он проходил сопряжение напрямую с главным устройством.

1. Узнайте имя или ID устройства компьютера с помощью `cbb status`.
2. На главном устройстве назначьте компьютер администратором:
   - **Компьютер с TPM 2.0 или Secure Enclave:**

     ```sh
     sudo cbb admin NAME
     ```

   - **Компьютер, ключи которого хранятся в файлах** (требует уровня ключей `files`, задаётся командой
     `sudo cbb keys files`):

     ```sh
     sudo cbb admin -allow-file-key NAME
     ```

     Любой, кто скопирует файлы ключей администратора с ключами в файлах, сможет действовать как
     администратор, пока другой администратор не удалит этот компьютер, поэтому назначайте только
     компьютеры, которые физически защищены и имеют шифрование диска.

**Результат:** `cbb status` показывает второй компьютер как администратора, и он может выполнять
`sudo cbb pair` и `sudo cbb remove NAME` для обычных участников.

Если главное устройство когда-нибудь потеряется или сломается, перенесите группу на другой компьютер
группы с помощью листа восстановления:

```sh
sudo cbb recovery -leave LOST-DEVICE
```

Затем введите по запросу ключ восстановления с листа (или передайте `-yubikey`, если вы записали его
на YubiKey). Полная процедура описана в разделе
[Если устройство потеряно или украдено](lost-device.md).

## Вступление из другой сети

Чтобы добавить компьютер, который не находится в вашей домашней сети, вы можете отправить
[приглашение через хаб](away-from-home.md#a-computer-that-is-not-at-home-an-invitation) либо выполнить
сопряжение через SSH-туннель или ваш собственный VPN.

### По SSH

1. На новом компьютере пробросьте локальный порт на порт участника главного устройства или
   администратора (по умолчанию 8764):

   ```sh
   ssh -N -L 18764:localhost:8764 user@admin-machine
   ```

2. В отдельном сеансе SSH на главном устройстве или компьютере-администраторе откройте окно
   сопряжения:

   ```sh
   sudo cbb pair
   ```

   Скопируйте полную строку `cbb://pair?...`, выведенную под 6 цифрами. (Без локального обнаружения
   в сети одних только 6 цифр недостаточно, чтобы определить окно; строка `cbb://pair?...` содержит и
   данные окна, и код.)

3. На новом компьютере вступите в группу через проброшенный порт и вставьте строку `cbb://pair?...`
   по запросу:

   ```sh
   sudo cbb pair -code 127.0.0.1:18764
   ```

**Результат:** новый компьютер вступает в группу через SSH-туннель внутри TLS 1.3.

### Через собственный VPN

1. В Linux, если вы настроили VPN уже после установки Connect Beyond Borders, запустите установщик
   снова, чтобы правила файрвола разрешили подсеть вашего VPN.
2. На главном устройстве или компьютере-администраторе выполните `sudo cbb pair` и скопируйте строку
   `cbb://pair?...`, выведенную под 6 цифрами.
3. На новом компьютере вступите в группу, указав VPN-адрес и порт компьютера-администратора, и
   вставьте строку `cbb://pair?...` по запросу:

   ```sh
   sudo cbb pair -code ADMIN-VPN-ADDRESS:8764
   ```

**Результат:** новый компьютер вступает в вашу группу через VPN внутри TLS 1.3.

Секрет сопряжения никогда не передаётся в открытом виде: оба компьютера вычисляют подтверждение сеанса
внутри TLS 1.3. Новый компьютер продолжает синхронизироваться по временному пути сопряжения, пока его
служба не перезапустится; чтобы синхронизация работала постоянно после закрытия SSH или вашего VPN,
сначала настройте [синхронизацию вне дома](away-from-home.md) на обоих устройствах.
