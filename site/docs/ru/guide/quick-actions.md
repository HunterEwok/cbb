# Быстрые действия

Для всех, кто хочет заблокировать, перевести в сон, перезагрузить, выключить компьютер или
запустить на нём заданную программу с телефона-администратора или другого компьютера-администратора
группы.

**Администратор** запускает быстрое действие одним нажатием или одной командой, а целевой компьютер
выполняет его, только если его собственный пользователь включил это действие локально. По умолчанию
все быстрые действия выключены, и никто не может включить действие на расстоянии.

## Встроенные действия

| Действие | Что делает | Поддерживаемые устройства |
|---|---|---|
| `lock` | Блокирует экран | Компьютеры, небольшие устройства |
| `sleep` | Переводит компьютер в сон | Компьютеры, небольшие устройства |
| `reboot` | Перезагружает компьютер после предупреждения за 1 минуту | Компьютеры, небольшие устройства |
| `shutdown` | Выключает компьютер после предупреждения за 1 минуту | Компьютеры, небольшие устройства |
| `cancel-shutdown` | Отменяет ожидающую перезагрузку или выключение | Компьютеры, небольшие устройства |
| `restart` | Перезапускает службу Connect Beyond Borders | Компьютеры, небольшие устройства |
| `keyboard-layout` | Переключает активную раскладку [Bluetooth-клавиатуры](keyboards-and-tvs.md) компьютера на следующую | Компьютеры с Linux с включённой Bluetooth-клавиатурой |

Задержка в 1 минуту перед `reboot` или `shutdown` даёт тому, кто работает за компьютером, время
сохранить работу или выполнить `cancel-shutdown`. В Windows вошедшие пользователи также видят
системное предупреждение.

В macOS и Windows действия сеанса (`lock`, `sleep` и собственные действия) выполняются через агента
буфера обмена вошедшего пользователя, поэтому в системе должен быть выполнен вход. В macOS для
`lock` нужно, чтобы в разделе **Системные настройки → Экран блокировки → Запрашивать пароль после
запуска заставки или выключения дисплея** было выбрано **Немедленно**.

## 1. Включите встроенное действие

Выполните эти команды на целевом компьютере (используйте `sudo` в Linux, macOS и FreeBSD; в Windows
используйте терминал администратора без `sudo`):

1. Выведите список всех действий и посмотрите, кому разрешено запускать каждое из них:

   ```sh
   cbb action
   ```

2. Включите действие:

   ```sh
   sudo cbb action enable lock
   ```

   Прочитайте, что разрешает действие, и введите `yes` (или передайте `-yes` в сценариях).

   **Результат:** Действие включится для каждого администратора вашей группы. В Linux Connect Beyond
   Borders записывает файл `/etc/polkit-1/rules.d/60-cbb.rules`, выдающий службе ровно те права
   polkit, которые нужны включённым действиям.

3. При желании ограничьте круг администраторов, которые могут запускать действие:
   - Ограничьте тип подписывающего устройства флагом `-by` (`root` для главного устройства, `phone`
     для телефонов-администраторов, `computer` для компьютеров-администраторов, `watch` для часов с
     ключом администратора):

     ```sh
     sudo cbb action enable reboot -by root,phone
     ```

   - По умолчанию `reboot` и `shutdown` принимают только администраторов, чьи ключи хранятся в
     оборудовании (телефон, Mac с Secure Enclave или ПК с TPM 2.0). Чтобы разрешить также
     администраторов с ключами в файлах, добавьте `-any-key`:

     ```sh
     sudo cbb action enable reboot -any-key
     ```

Чтобы снова выключить одно действие:

```sh
sudo cbb action disable lock
```

**Результат:** Действие выключится немедленно. В Linux выключение обновляет или удаляет правило
polkit, отзывая неиспользуемые права.

## 2. Добавьте собственное действие

На одном компьютере можно задать до 32 собственных действий (имя должно состоять из 1–32 строчных
латинских букв, цифр или дефисов и начинаться с буквы).

1. Зарегистрируйте команду на целевом компьютере, указав полный путь к программе после `--`:

   ```sh
   sudo cbb action add backup -by phone -- /usr/local/bin/backup.sh --quick
   ```

2. Прочитайте сводку о том, что разрешает действие, и введите `yes`.

**Результат:** Connect Beyond Borders сохранит команду в ваших пользовательских настройках
(`own-actions.json`), чтобы только агент вошедшего пользователя мог запускать именно этот
исполняемый файл с этим списком аргументов без оболочки. Отправитель получает только код завершения.
Команды должны завершаться в течение 15 секунд; более долгие задачи запускайте в фоне.

Чтобы удалить собственное действие:

```sh
sudo cbb action remove backup
```

## 3. Запустите действие от имени администратора

- **С компьютера-администратора (в терминале):**

  ```sh
  cbb action -on DEVICE NAME
  ```

  Замените `DEVICE` на имя целевого устройства или его ID из `cbb status`, а `NAME` — на имя
  действия.

  **Результат:** `cbb` выведет, выполнилось ли действие или почему целевое устройство его
  отклонило.

- **С телефона-администратора:**
  1. Откройте **CBB** и нажмите на целевой компьютер в сети на главном экране.
  2. В разделе **Быстрые действия** нажмите на нужное действие.
  3. Подтвердите действие лицом, отпечатком пальца, код-паролем или (на ОС Аврора) вашим PIN
     администратора. `reboot` и `shutdown` запрашивают повторное подтверждение.

  **Результат:** Целевое устройство выполнит действие, а телефон покажет **Готово.**

## 4. Выключите все действия

- **Локально на целевом компьютере:**

  ```sh
  sudo cbb action off
  ```

- **Удалённо с любого компьютера-администратора:**

  ```sh
  sudo cbb action off -on DEVICE     # one computer
  sudo cbb action off -all           # every computer in the group
  ```

- **Удалённо с телефона-администратора:** Откройте страницу устройства на главном экране и нажмите
  **Выключить все**.

**Результат:** Все быстрые действия на затронутых компьютерах выключатся немедленно. Включить их
снова сможет только пользователь каждого компьютера локально.

Каждый целевой компьютер ведёт журнал аудита (`actions-log.json`) последних 100 запросов действий с
указанием того, кто и когда запросил каждое действие. Точные ограничения см. в разделе
[Ограничения и сроки](../reference/limits.md#remote-paste-and-quick-actions).
