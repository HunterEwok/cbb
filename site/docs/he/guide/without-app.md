# בלי האפליקציה

למי שרוצה ליצור ולנהל קבוצה של Connect Beyond Borders באמצעות מחשבים בלבד, בלי אפליקציית טלפון. בדף הזה תיצרו קבוצה במחשב אחד, תוסיפו עוד מחשבים ברשת הביתית שלכם, תגדירו מנהל שני, ותוסיפו מחשבים מרשת אחרת דרך SSH או VPN.

![מחשב Linux מחזיק את הקבוצה ומוסיף את ה-Mac ואת Windows בקוד בן שש ספרות](../images/without-app.svg)

מחשב שיוצר קבוצה הופך ל**מכשיר הראשי** שלה (נקרא *root* בכלי שורת הפקודה ובתרשימים). [התקנת Linux ללא root](install.md#without-sudo-rootless) לעולם לא יכולה להיות המכשיר הראשי או מנהל, ומכולת Docker דורשת `CBB_KEYS_IN_FILE=yes` בסביבה שלה לפני שהיא מחזיקה מפתחות קבוצה.

## 1. צרו את הקבוצה במחשב

בחרו מחשב שדולק באופן קבוע (Linux,‏ macOS,‏ Windows או FreeBSD) ו[התקינו את Connect Beyond Borders](install.md).

1. הריצו במחשב הזה (השמיטו את `sudo` במסוף מנהל ב-Windows, או לחצו **יצירת קבוצה** באפליקציית ה-Mac או באפליקציית המגש):

   ```sh
   sudo cbb new
   ```

2. שמרו את **דף השחזור** שמוצג על המסך — ארבע שורות של אותיות וספרות ועוד קוד QR. הדפיסו או רשמו אותו ושמרו אותו בנפרד מהמכשירים שלכם.

**תוצאה:** המחשב הזה הופך למכשיר הראשי של הקבוצה. במחשב Mac עם שבב Apple או שבב T2, או במחשב Linux או Windows עם TPM 2.0, המפתחות שלו נמצאים בחומרת אבטחה; אחרת הם נשמרים בקבצים מוגנים (`cbb keys` מתחיל ב-`files`; ראו [מפתחות ואימות](keys.md)). שום דבר לא שומר עותק של דף השחזור — זו הדרך היחידה להעביר את הקבוצה אם המחשב הזה אובד.

## 2. הוסיפו מחשבים ברשת הביתית שלכם

התקינו את Connect Beyond Borders בכל מחשב נוסף באותה רשת ביתית, ואז צמדו אותו:

1. במכשיר הראשי (או בכל מחשב מנהל), פתחו חלון צימוד:

   ```sh
   sudo cbb pair
   ```

   **תוצאה:** המסוף מציג קוד צימוד בן 6 ספרות וקוד QR, וממתין 5 דקות. אפשר לפתוח חלון צימוד גם מכפתור **+** באפליקציית ה-Mac או באפליקציית המגש.

2. במחשב החדש, הצטרפו לקבוצה:
   - **מסוף:** הריצו `sudo cbb pair -code` (השמיטו את `sudo` במסוף מנהל ב-Windows) והקלידו את 6 הספרות כשתתבקשו.
   - **אפליקציית שולחן עבודה:** פתחו את **CBB**, בחרו **הצטרפות לקבוצה**, והקלידו את 6 הספרות.

   כל קוד שגוי מנצל אחד מ-3 ניסיונות; החלון נסגר אחרי 3 ניסיונות כושלים או ברגע שמכשיר מצטרף.

**תוצאה:** שני המחשבים מאשרים את ההצטרפות, ולוחות ההעתקה שלכם מסתנכרנים אוטומטית. העתיקו טקסט במחשב אחד והדביקו אותו באחר כדי לוודא (ראו [התחלה מהירה: העתיקו במכשיר אחד, הדביקו באחר](quickstart.md#4-copy-on-one-paste-on-another)).

## 3. הוסיפו מנהל שני ושמרו על דף השחזור שלכם

קדמו מחשב שני ל**מנהל** כדי שעדיין תוכלו להוסיף ולהסיר מכשירים כשהמכשיר הראשי לא מחובר. שימו לב שמחשב יכול להתקדם למנהל רק אם צומד ישירות למכשיר הראשי.

1. מצאו את השם או מזהה המכשיר של המחשב באמצעות `cbb status`.
2. במכשיר הראשי, קדמו את המחשב:
   - **מחשב עם TPM 2.0 או Secure Enclave:**

     ```sh
     sudo cbb admin NAME
     ```

   - **מחשב שהמפתחות שלו נמצאים בקבצים** (דורש רמת מפתחות `files`, המוגדרת עם `sudo cbb keys files`):

     ```sh
     sudo cbb admin -allow-file-key NAME
     ```

     כל מי שמעתיק את קובצי המפתחות של מנהל עם מפתח בקובץ יכול לפעול כמנהל עד שמנהל אחר מסיר את המחשב הזה, לכן קדמו רק מחשבים שאתם שומרים מאובטחים פיזית ועם הצפנת דיסק.

**תוצאה:** `cbb status` מציג את המחשב השני כמנהל, והוא יכול להריץ `sudo cbb pair` ו-`sudo cbb remove NAME` עבור חברים רגילים.

אם המכשיר הראשי אבד או התקלקל אי פעם, העבירו את הקבוצה למחשב אחר בקבוצה בעזרת דף השחזור שלכם:

```sh
sudo cbb recovery -leave LOST-DEVICE
```

אחר כך הקלידו את מפתח השחזור מהדף כשתתבקשו (או העבירו `-yubikey` אם אטמתם אותו על YubiKey). ראו [אם מכשיר אבד או נגנב](lost-device.md) להליך המלא.

## הצטרפות מרשת אחרת

כדי להוסיף מחשב שאינו נמצא ברשת הביתית שלכם, אפשר לשלוח [הזמנה דרך רכזת](away-from-home.md#a-computer-that-is-not-at-home-an-invitation), או לצמד דרך מנהרת SSH או ה-VPN שלכם.

### דרך SSH

1. במחשב החדש, העבירו יציאה מקומית אל יציאת החבר של המכשיר הראשי או של המנהל (8764 כברירת מחדל):

   ```sh
   ssh -N -L 18764:localhost:8764 user@admin-machine
   ```

2. בהפעלת SSH נפרדת במכשיר הראשי או במחשב המנהל, פתחו חלון צימוד:

   ```sh
   sudo cbb pair
   ```

   העתיקו את השורה המלאה `cbb://pair?...` המודפסת מתחת ל-6 הספרות. (בלי גילוי ברשת המקומית, 6 הספרות לבדן אינן יכולות לזהות את החלון; השורה `cbb://pair?...` נושאת גם את פרטי החלון וגם את הקוד.)

3. במחשב החדש, הצטרפו דרך היציאה המועברת והדביקו את השורה `cbb://pair?...` כשתתבקשו:

   ```sh
   sudo cbb pair -code 127.0.0.1:18764
   ```

**תוצאה:** המחשב החדש מצטרף לקבוצה דרך מנהרת ה-SSH בתוך TLS 1.3.

### דרך ה-VPN שלכם

1. ב-Linux, אם הגדרתם את ה-VPN אחרי שהתקנתם את Connect Beyond Borders, הריצו שוב את תוכנית ההתקנה כדי שכללי חומת האש יתירו את תת-הרשת של ה-VPN שלכם.
2. במכשיר הראשי או במחשב המנהל, הריצו `sudo cbb pair` והעתיקו את השורה `cbb://pair?...` המודפסת מתחת ל-6 הספרות.
3. במחשב החדש, הצטרפו באמצעות כתובת ה-VPN והיציאה של מחשב המנהל, והדביקו את השורה `cbb://pair?...` כשתתבקשו:

   ```sh
   sudo cbb pair -code ADMIN-VPN-ADDRESS:8764
   ```

**תוצאה:** המחשב החדש מצטרף לקבוצה שלכם דרך ה-VPN בתוך TLS 1.3.

סוד הצימוד לעולם אינו עובר בגלוי: שני המחשבים גוזרים הוכחת הפעלה בתוך TLS 1.3. המחשב החדש ממשיך להסתנכרן דרך נתיב הצימוד הזמני עד שהשירות שלו מופעל מחדש; כדי להמשיך להסתנכרן באופן קבוע אחרי סגירת SSH או ה-VPN שלכם, הגדירו קודם [סנכרון מחוץ לבית](away-from-home.md) בשני המכשירים.
