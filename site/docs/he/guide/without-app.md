# בלי האפליקציה

קבוצה של מחשבים לא צריכה את אפליקציית הטלפון: מחשב יכול להחזיק את הקבוצה.

![מחשב Linux מחזיק את הקבוצה ומוסיף את ה-Mac ואת Windows בקוד בן שש ספרות](../images/without-app.svg)

## 1. צרו את הקבוצה במחשב

[התקינו](install.md) את Copy Beyond Borders במחשב שדלוק לעיתים קרובות: Linux, Windows, Mac או FreeBSD. הוא מחזיק את הקבוצה. אחר כך:

```sh
sudo cbb new
```

המחשב הזה הוא עכשיו ה**שורש** של הקבוצה: הוא מחזיק את מפתח הקבוצה ומוסיף ומסיר מכשירים. המפתח שלו נמצא ב-TPM או ב-Secure Enclave של המחשב אם יש לו כזה, ואחרת בקובץ המוגן על ידי המערכת.

‏`cbb new` מציג גם פעם אחת את **דף השחזור** של הקבוצה: ארבע שורות של אותיות וספרות וקוד QR. רשמו אותו או הדפיסו את המסך, ושמרו אותו בנפרד מהמכשירים שלכם. בעזרתו תחזירו את הקבוצה אם המחשב הזה יאבד (‏`cbb recovery`); אף אחד לא שומר עותק.

## 2. הוסיפו מחשבים

בשורש:

```sh
sudo cbb pair
```

הוא פותח חלון צימוד, מציג קוד בן שש ספרות ומחכה. במחשב החדש הריצו `sudo cbb pair -code` והקלידו את הקוד הזה: הוא מוצא את החלון ברשת הביתית ומצטרף תוך שניות. קוד שגוי מנצל אחד משלושה ניסיונות; החלון נסגר אחרי השלישי, או כשמחשב הצטרף.

אחר כך כל מחשב מסתנכרן, כמו ב[התחלה מהירה](quickstart.md#4-copy-on-one-paste-on-another).

## 3. אל תסתמכו על מחשב אחד

הפכו מחשב שני למנהל, כדי שגם הוא יוכל להוסיף ולהסיר מכשירים:

```sh
sudo cbb admin NAME                   # on the root; NAME as cbb status shows it, and it must be on
sudo cbb admin -allow-file-key NAME   # for a computer without a TPM or a Secure Enclave
```

מחשב Linux או Windows עם TPM שומר שם את מפתח המנהל, ו-Mac ב-Secure Enclave שלו. מחשב בלי אף אחד מהם שומר אותו בקובץ, ולכן `cbb admin` דורש קודם `-allow-file-key`: מי שמעתיק את הקובץ הזה פועל כמנהל עד שמנהל אחר מסיר את המחשב, ולכן הפכו למנהל רק מחשב ששמור אצלכם היטב.

אם השורש אבד או התקלקל, מחשב אחר הופך לשורש בעזרת דף השחזור של הקבוצה, וכל שאר המכשירים נשארים:

```sh
sudo cbb recovery            # then type the recovery key from the sheet
```

עוד ב[אם מכשיר אבד או נגנב](lost-device.md).

## הצטרפות מרשת אחרת

מחשב שאינו בבית מצטרף בהזמנה מהרכזת ([מחוץ לבית](away-from-home.md#a-computer-that-is-not-at-home-an-invitation)), או דרך חיבור שאתם כבר שולטים בו:

- **SSH** אל השורש או אל מנהל: במחשב החדש הריצו `ssh -N -L 18764:localhost:8764 user@that-machine`, ואז `sudo cbb pair` שם (בהפעלת SSH אחרת) ו-`sudo cbb pair -code 127.0.0.1:18764` כאן.
- **VPN משלכם** שנותן לשתי המכונות כתובות פרטיות: `sudo cbb pair` בשורש או במנהל, ואז `sudo cbb pair -code ITS-VPN-ADDRESS:8764` כאן. ב-Linux, הריצו את המתקין שוב אחרי הגדרת ה-VPN, כדי שכללי חומת האש שלו יתירו את רשת ה-VPN.

בשני המקרים, הקלידו את השורה ש-`cbb pair` מדפיס מתחת לקוד (`cbb://pair?...`) במקום שש הספרות: הספרות לבדן אינן מציינות שום חלון במקום ש-mDNS לא מגיע אליו, והשורה מציינת אותו, עם אותו קוד בתוכה.

הקודים אף פעם לא עוברים ברשת: כל מחשב מחשב את הקוד שלו מתוך הצימוד, שעובר בתוך SSH או ה-VPN שלכם, ובתוך TLS. המחשב החדש מסתנכרן בנתיב הזה עד שהשירות שלו מופעל מחדש; כדי להמשיך לסנכרן אחר כך, הפעילו [סנכרון מחוץ לבית](away-from-home.md) בשניהם לפני שאתם סוגרים את החיבור.

## קבוצה מלפני 0.6

גרסה 0.6 קוראת רק רשומות קבוצה בגרסה 2, ואין בה דרך חזרה לקבוצות ישנות. מחשב שעודכן מגרסה קודמת עוזב את הקבוצה הישנה שלו בהפעלה הראשונה: הוא מעביר את קובצי הקבוצה אל `before-0.6` בתיקיית המצב שלו, שומר את ההגדרות, ו-`cbb status` מציין זאת. הקימו את הקבוצה מחדש: `cbb new` במחשב אחד, ואז `cbb pair -code` בשאר.
