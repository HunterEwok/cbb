# מקלדות וטלוויזיות

למי שרוצה להקליד סיסמה ארוכה, כתובת URL או שאילתת חיפוש בטלוויזיה, בטאבלט, בקונסולת משחקים או במחשב שאינם מריצים את Connect Beyond Borders. מכשיר אחד בקבוצה שלכם פועל כמקלדת Bluetooth, כמקלדת USB או כשלט רשת של הטלוויזיה.

מקלדות ושלטי טלוויזיה הם תכונות ניסיוניות ב[המעבדה](lab.md). למצב הבדיקה הנוכחי בחומרה אמיתית, ראו [שוויון בין פלטפורמות](../parity.md#on-real-devices).

## התאימו את פריסת המקלדת והמהירות

מקלדת Bluetooth או USB שולחת קודי מקשים פיזיים, לא תווים: מכשיר היעד הופך כל קוד מקש לתו לפי פריסת המקלדת הפעילה בו.

- **פריסה:** הגדירו את פריסת המקלדת ב-Connect Beyond Borders כך שתתאים לפריסה הפעילה במכשיר היעד — **אנגלית (ארה״ב)** (`us`) או **רוסית** (`ru`). אם הטקסט שלכם מכיל תו שהפריסה שנבחרה אינה יכולה להקליד, Connect Beyond Borders דוחה את הטקסט כולו ומציין את התווים שאינם נתמכים במקום להקליד תווים שגויים. מעברי שורה שולחים Enter וטאבים שולחים Tab.
- **מהירות:** ברירת המחדל להקלדה היא **20 תווים בשנייה**, כי חלק מהטלוויזיות משמיטות מקשים שמגיעים מהר יותר. הנמיכו את המהירות (לדוגמה, ל-10 תווים בשנייה) אם חסרים תווים.
- **מגבלת אורך:** מקלדת Bluetooth או USB מקלידה לכל היותר **4,096 תווים** בכל פעם.

## טלפון כמקלדת Bluetooth

נתמך בטלפוני **Android**,‏ **Aurora OS** ו-**HarmonyOS**.

1. פתחו את **CBB**, עברו אל **הגדרות**, הפעילו **הגדרות מתקדמות**, ופתחו **מעבדה > מקלדת Bluetooth**.
2. הפעילו את **שימוש כמקלדת Bluetooth** ואשרו הרשאת Bluetooth אם תתבקשו.
   - ב-Android, אם האפליקציה מדווחת שהטלפון לא יכול לשמש כמקלדת, יצרן המכשיר השמיט את פרופיל Bluetooth HID Device; השתמשו בשיטה אחרת. אם אפליקציה אחרת מחזיקה בפרופיל המקלדת, כבו אותו שם קודם, כי Android מאפשר רק אפליקציית מקלדת אחת בכל פעם.
3. צמדו את מכשיר היעד לטלפון שלכם:
   - **Android:** הקישו על **הפיכת הטלפון לגלוי** (גלוי למשך 2 דקות), צמדו את הטלפון בהגדרות ה-Bluetooth של מכשיר היעד, ואז בחרו את היעד תחת **הקלדה ב**.
   - **Aurora OS:** הקישו על **הפיכת הטלפון לגלוי** (גלוי למשך 2 דקות) והתחברו אל `CBB keyboard` מהגדרות ה-Bluetooth של מכשיר היעד.
   - **HarmonyOS:** בזמן שמתג המקלדת פועל, התחברו אל הטלפון שלכם לפי שם המכשיר שלו מהגדרות ה-Bluetooth של מכשיר היעד.

   **תוצאה:** המסך מציג `Connected to …` (או `A device is connected.`).

4. הגדירו את **פריסת המקלדת של המכשיר** (`English (US)` או `Russian`) ואם צריך, את **מהירות** (`10`, `20` או `40` תווים בשנייה).
5. העבירו את המיקוד לשדה טקסט במכשיר היעד, ואז הקישו על **הקלדת הלוח** (ב-HarmonyOS, הקישו על כפתור המערכת **הדבקה** שליד **הקלדת הלוח**).

**תוצאה:** הטלפון שלכם מקליד את הטקסט מהלוח אל השדה שבמיקוד במכשיר היעד.

## מחשב Linux כמקלדת Bluetooth

הריצו את הפקודות האלה במחשב Linux שמותקן בו `cbb-helper`:

1. רשמו את מקלדת ה-Bluetooth LE ב-BlueZ:

   ```sh
   sudo cbb keyboard on -layout us
   ```

   דגלים אופציונליים: `-rate N` (5 עד 60 תווים בשנייה; ברירת מחדל 20) ו-`-pastes` (מנתב [הדבקות מרחוק](remote-paste.md) נכנסות אל מכשיר ה-Bluetooth המצומד במקום אל מסך המחשב הזה; מעברי שורה דורשים `sudo cbb paste-receive on -enter`).

2. הפכו את המחשב לגלוי למשך 2 דקות:

   ```sh
   sudo cbb keyboard pair
   ```

3. במכשיר היעד, פתחו את הגדרות ה-Bluetooth שלו וצמדו עם `CBB <your computer name>`.
4. בדקו את החיבור והקלידו טקסט:

   ```sh
   cbb keyboard
   echo 'the text' | sudo cbb keyboard type
   ```

**תוצאה:** `cbb keyboard` מאשר שמכשיר מחובר, ו-`cbb keyboard type` מדפיס `Typed.` אחרי שליחת הטקסט. מקלדות ועכברי ה-Bluetooth של מחשב ה-Linux עצמו ממשיכים לעבוד כרגיל.

כדי לכבות את מקלדת ה-Bluetooth, הריצו `sudo cbb keyboard off`.

## ה-Nano ESP32 כמקלדת USB או Bluetooth

[קושחת Arduino Nano ESP32](../../esp32/README.md) מריצה מקלדת אתחול (boot) ב-USB ומקלדת Bluetooth LE הנשלטות מהקונסולה הטורית שלה (הצטרפות לקבוצה וסנכרון לוח נמצאים ב[מפת הדרכים](../roadmap.md)).

1. התחברו לקונסולה הטורית של הלוח ובחרו מצב:
   - **מקלדת USB:** הריצו `usb keyboard`. הלוח מופעל מחדש כשיציאת ה-USB-C שלו פועלת גם כמקלדת אתחול (שעובדת ב-BIOS/UEFI, בבקשות הצפנת דיסק ובקונסולות) וגם כקונסולה טורית. חברו את הלוח למכשיר היעד.
   - **מקלדת Bluetooth LE:** הריצו `ble on`, אחר כך `ble pair`, וצמדו את `CBB Nano ESP32` בהגדרות ה-Bluetooth של מכשיר היעד בתוך 2 דקות. הלוח זוכר עד 4 מארחים מצומדים (`ble forget` מנקה אותם).
2. הגדירו את הפריסה ומהירות ההקלדה של מכשיר היעד:

   ```text
   layout us
   rate 20
   ```

   השתמשו ב-`layout ru` עבור רוסית.
3. בקושחה שנבנתה עם `--features console-type`, הקלידו טקסט עם:

   ```text
   type hello world
   ```

**תוצאה:** הלוח מקליד במארח ה-Bluetooth המחובר אם יש כזה פעיל, או במקלדת ה-USB אחרת.

## מחשב כשלט של הטלוויזיה

כל מחשב Linux,‏ macOS,‏ Windows או FreeBSD עם `cbb-helper` ברשת הביתית שלכם יכול להקליד ב-Android TV, ב-Google TV, ב-Apple TV או ב-Roku דרך הרשת המקומית. שום דבר לא מותקן בטלוויזיה, והטלוויזיה לעולם אינה מצטרפת לקבוצה שלכם. השתמשו ב-`sudo` במערכות Unix (השמיטו את `sudo` במסוף מנהל מערכת ב-Windows).

### 1. צמדו או הוסיפו את הטלוויזיה

בחרו את הפקודות המתאימות לטלוויזיה שלכם:

- **Android TV או Google TV:**

  ```sh
  sudo cbb remote add -name living-room-tv living-room-tv.lan
  sudo cbb remote code
  ```

  הקלידו את הקוד בן 6 הספרות שמוצג על מסך הטלוויזיה בתוך 2 דקות.

- **Apple TV:** קודם הגדירו ב-Apple TV את **הגדרות > AirPlay ו-HomeKit > אפשר גישה** אל **כל מי שנמצא באותה רשת** (**רק אנשים שמשתפים את הבית הזה** דוחה צימוד). אחר כך הריצו:

  ```sh
  sudo cbb remote add -appletv -name lounge 192.168.1.30
  sudo cbb remote code
  ```

  הקלידו את ה-PIN בן 4 הספרות שמוצג ב-Apple TV בתוך 2 דקות.

- **Roku:** פרוטוקול External Control Protocol של Roku משתמש ב-HTTP לא מוצפן בלי צימוד. קודם הגדירו ב-Roku את **הגדרות > מערכת > הגדרות מערכת מתקדמות > שליטה על ידי אפליקציות לנייד** אל **מופעל** או **מתירני**. אחר כך הוסיפו אותו עם `-consent`:

  ```sh
  sudo cbb remote add -roku -consent 192.168.1.40
  ```

**תוצאה:** הריצו `cbb remote` בלי ארגומנטים כדי לוודא שהטלוויזיה מופיעה ברשימה שלכם.

### 2. הקלידו בטלוויזיה או העבירו הדבקות מרחוק

1. פתחו תיבת חיפוש או שדה טקסט בטלוויזיה בעזרת השלט שלה.
2. הקלידו טקסט מהמחשב:

   ```sh
   echo 'the film' | sudo cbb remote type
   ```

   הוסיפו `-tv NAME` כשמוגדרת אצלכם יותר מטלוויזיה אחת. ב-Android TV וב-Roku, מעברי שורה לוחצים על Enter; ב-Apple TV, מעברי שורה נשארים בתוך הטקסט.

   **תוצאה:** הטקסט מופיע בשדה הטקסט שבמיקוד בטלוויזיה ו-`cbb remote type` מדפיס `Typed.`

3. לחלופין, נתבו [הדבקות מרחוק](remote-paste.md) נכנסות מהמנהלים בקבוצה שלכם אל הטלוויזיה (טלוויזיה אחת בכל פעם; מעברי שורה דורשים `sudo cbb paste-receive on -enter`):

   ```sh
   sudo cbb remote pastes living-room-tv on
   ```

כדי לשכוח טלוויזיה, הריצו `sudo cbb remote remove NAME`. אם Android TV או Apple TV מאופסים או שוכחים את המחשב שלכם, צמדו אותם שוב.

## בטיחות

- **מקלדות Bluetooth:** מקלדת Bluetooth מקלידה בכל מקום שבו יש למכשיר המצומד מיקוד מקלדת. צמדו רק עם מכשירים שאתם מתכוונים לשלוט בהם, ושכחו את הצימוד בשני הצדדים כשאתם מפסיקים להשתמש בו.
- **הדבקות מרחוק למקלדות ולטלוויזיות:** בזמן שהעברת הדבקות מרחוק מופעלת (`-pastes` או `cbb remote pastes TV on`), כל מנהל בקבוצה שלכם יכול להקליד במכשיר הזה. כיבוי הדבקה מרחוק עוצר גם את ההעברה.
- **רשת ביתית בלבד לטלוויזיות:** `cbb remote` מתחבר רק לכתובות ברשת הביתית שלכם ודוחה כל כתובת מחוצה לה.
- **בלי סיסמאות ל-Roku:** טקסט שנשלח ל-Roku עובר ברשת הביתית שלכם כ-HTTP גלוי. לעולם אל תשלחו סיסמאות או סודות אחרים ל-Roku.

לכל דגלי שורת הפקודה, ראו [פקודות](../reference/cli.md). ליציאות הרשת של הטלוויזיות, ראו [מכשירים, יציאות וקבצים](../reference/devices.md#ports).
