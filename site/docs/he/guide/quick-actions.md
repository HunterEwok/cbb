# פעולות מהירות

למי שרוצה לנעול, להעביר למצב שינה, להפעיל מחדש, לכבות או להריץ תוכנה קבועה במחשב מתוך טלפון מנהל או מחשב מנהל אחר בקבוצה.

**מנהל** מריץ פעולה מהירה בהקשה אחת או בפקודה אחת, ומחשב היעד מריץ אותה רק אם המשתמש של אותו מחשב הפעיל את הפעולה הזו מקומית. כל פעולה מהירה מתחילה כבויה כברירת מחדל, ואיש אינו יכול להפעיל פעולה מרחוק.

## פעולות מובנות

| פעולה | מה היא עושה | מכשירים נתמכים |
|---|---|---|
| `lock` | נועלת את המסך | מחשבים, מכשירים קטנים |
| `sleep` | מעבירה את המחשב למצב שינה | מחשבים, מכשירים קטנים |
| `reboot` | מפעילה מחדש את המחשב אחרי אזהרה של דקה | מחשבים, מכשירים קטנים |
| `shutdown` | מכבה את המחשב אחרי אזהרה של דקה | מחשבים, מכשירים קטנים |
| `cancel-shutdown` | מבטלת הפעלה מחדש או כיבוי שממתינים | מחשבים, מכשירים קטנים |
| `restart` | מפעילה מחדש את שירות Connect Beyond Borders | מחשבים, מכשירים קטנים |
| `keyboard-layout` | מעבירה את הפריסה הפעילה של [מקלדת ה-Bluetooth](keyboards-and-tvs.md) של המחשב לפריסה הבאה | מחשבי Linux שמקלדת ה-Bluetooth פועלת בהם |

השהיה של דקה לפני `reboot` או `shutdown` נותנת לכל מי שנמצא ליד המחשב זמן לשמור עבודה או להריץ `cancel-shutdown`. ב-Windows, משתמשים מחוברים רואים גם אזהרת מערכת.

ב-macOS וב-Windows, פעולות הפעלה (`lock`,‏ `sleep` ופעולות מותאמות אישית) רצות דרך סוכן הלוח של המשתמש המחובר, ולכן מישהו חייב להיות מחובר. ב-macOS, ‏`lock` דורשת שההגדרה **הגדרות המערכת > מסך נעילה > בקש סיסמה לאחר ששומר המסך מתחיל או שהתצוגה כבויה** תהיה מוגדרת ל-**באופן מיידי**.

## 1. הפעילו פעולה מובנית

הריצו את הפקודות האלה במחשב היעד (השתמשו ב-`sudo` ב-Linux, ב-macOS וב-FreeBSD; השתמשו במסוף מנהל מערכת בלי `sudo` ב-Windows):

1. הציגו את כל הפעולות וראו מי רשאי להריץ כל אחת מהן:

   ```sh
   cbb action
   ```

2. הפעילו פעולה:

   ```sh
   sudo cbb action enable lock
   ```

   קראו מה הפעולה מתירה והקלידו `yes` (או העבירו `-yes` בסקריפטים).

   **תוצאה:** הפעולה מופעלת עבור כל מנהל בקבוצה שלכם. ב-Linux, ‏Connect Beyond Borders כותב את `/etc/polkit-1/rules.d/60-cbb.rules` ומעניק לשירות רק את הרשאות ה-polkit הדרושות לפעולות המופעלות.

3. לחלופין, הגבילו אילו מנהלים יכולים להריץ פעולה:
   - הגבילו לפי סוג החותם עם `-by` (`root` עבור המכשיר הראשי, `phone` עבור טלפוני מנהלים, `computer` עבור מחשבי מנהלים, `watch` עבור שעון חותם):

     ```sh
     sudo cbb action enable reboot -by root,phone
     ```

   - כברירת מחדל, `reboot` ו-`shutdown` מקבלות רק מנהלים שהמפתחות שלהם נמצאים בחומרה (טלפון, Mac עם Secure Enclave או מחשב עם TPM 2.0). כדי להתיר גם למנהלים עם מפתחות בקובץ, הוסיפו `-any-key`:

     ```sh
     sudo cbb action enable reboot -any-key
     ```

כדי לכבות שוב פעולה אחת:

```sh
sudo cbb action disable lock
```

**תוצאה:** הפעולה נכבית מיד. ב-Linux, השבתה מעדכנת או מסירה את כלל ה-polkit כך שהרשאות שאינן בשימוש מבוטלות.

## 2. הוסיפו פעולה משלכם

תוכלו להגדיר עד 32 פעולות מותאמות אישית לכל מחשב (השמות חייבים להיות באורך 1 עד 32 תווים של אותיות אנגליות קטנות, ספרות או מקפים, ולהתחיל באות).

1. רשמו את הפקודה במחשב היעד, ותנו את הנתיב המלא לתוכנה אחרי `--`:

   ```sh
   sudo cbb action add backup -by phone -- /usr/local/bin/backup.sh --quick
   ```

2. קראו את הסיכום של מה שהפעולה מתירה והקלידו `yes`.

**תוצאה:** Connect Beyond Borders שומר את הפקודה בהגדרות המשתמש שלכם (`own-actions.json`) כך שרק הסוכן של המשתמש המחובר יכול להריץ את קובץ ההפעלה המדויק הזה ואת רשימת הארגומנטים הזו בלי shell. השולח מקבל רק את קוד היציאה. פקודות חייבות להסתיים בתוך 15 שניות; הפעילו משימות ארוכות יותר ברקע.

כדי להסיר פעולה מותאמת אישית:

```sh
sudo cbb action remove backup
```

## 3. הריצו פעולה ממנהל

- **ממחשב מנהל (מסוף):**

  ```sh
  cbb action -on DEVICE NAME
  ```

  החליפו את `DEVICE` בשם היעד או במזהה המכשיר מתוך `cbb status`, ואת `NAME` בשם הפעולה.

  **תוצאה:** `cbb` מדפיס אם הפעולה רצה או מדוע היעד דחה אותה.

- **מטלפון מנהל:**
  1. פתחו את **CBB** והקישו על מחשב היעד המחובר ב**מסך הבית**.
  2. תחת **פעולות מהירות**, הקישו על הפעולה שתרצו להריץ.
  3. אשרו באמצעות פנים, טביעת אצבע, קוד גישה או (ב-Aurora OS) קוד ה-PIN של המנהל. `reboot` ו-`shutdown` מבקשות אישור שני.

  **תוצאה:** היעד מריץ את הפעולה והטלפון מציג **בוצע.**

## 4. כבו את כל הפעולות

- **מקומית במחשב היעד:**

  ```sh
  sudo cbb action off
  ```

- **מרחוק מכל מחשב מנהל:**

  ```sh
  sudo cbb action off -on DEVICE     # one computer
  sudo cbb action off -all           # every computer in the group
  ```

- **מרחוק מטלפון מנהל:** פתחו את דף המכשיר ב**מסך הבית** והקישו על **כיבוי הכול**.

**תוצאה:** כל פעולה מהירה במחשבים המושפעים נכבית מיד. רק המשתמש של כל מחשב עצמו יכול להפעיל אותן שוב מקומית.

כל מחשב יעד שומר יומן ביקורת (`actions-log.json`) של 100 בקשות הפעולה האחרונות, המתעד מי ביקש כל פעולה ומתי. למגבלות המדויקות, ראו [מגבלות ותוקף](../reference/limits.md#remote-paste-and-quick-actions).
