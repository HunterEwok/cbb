# אם מכשיר אבד או נגנב

למי שהטלפון, המחשב או מכשיר אחר בקבוצה שלו אבד או נגנב. בדף הזה תסירו את המכשיר שאבד, תקפיאו מחשב מנהל שנגנב, תעבירו את הקבוצה למכשיר ראשי חדש אם המכשיר הראשי שלכם איננו, ותכבו תכונות מרחוק במכשירים שנותרו לכם.

הסירו מכשיר חסר ברגע שאתם שמים לב שהוא איננו. שאר המכשירים שלכם נשארים בקבוצה וממשיכים להסתנכרן בלי צורך לצמד מחדש.

## 1. הסירו את המכשיר שאבד

הסרת מכשיר מפיצה רשומת הסרה חתומה, כך שכל מכשיר אחר דוחה חיבורים ממנו ומפסיק לאטום העתקות עבורו. רק **המכשיר הראשי** (שנקרא *root* בכלי שורת הפקודה) או **טלפון מנהל** יכולים להסיר מנהל אחר; מחשב מנהל מסיר חברים רגילים בלבד.

- **במכשיר הראשי או בטלפון מנהל:**
  1. פתחו את **CBB** והקישו על המכשיר שאבד ב**מסך הבית**.
  2. הקישו על **הסרה** ואשרו באמצעות פנים, טביעת אצבע, קוד גישה או (ב-Aurora OS) קוד ה-PIN של המנהל.
- **במכשיר הראשי או במחשב מנהל (במסוף):**

  ```sh
  sudo cbb remove NAME
  ```

  החליפו את `NAME` בשם המכשיר או במזהה המכשיר מתוך `cbb status` (השמיטו את `sudo` במסוף מנהל מערכת ב-Windows).
- **באפליקציית ה-Mac או באפליקציית מגש המערכת (מכשיר ראשי או מנהל):** פתחו את חלונית הפרטים של המכשיר שאבד, לחצו על **הסרה** ואשרו.

**תוצאה:** כל מכשיר מחובר דוחה מיד את המכשיר שהוסר, ומכשירים שאינם מחוברים דוחים אותו ברגע שהם מתחברים מחדש. מכשיר שהוסר יכול להצטרף שוב רק באמצעות צימוד מחדש כמכשיר חדש.

## 2. אם זה היה מחשב מנהל: הקפיאו אותו קודם

מחשב מנהל יכול לחתום על שינויים בקבוצה ולשלוח פקודות. אם ייתכן שמחשב מנהל נמצא בידיים של מישהו אחר ואין לכם בהישג יד את המכשיר הראשי או טלפון מנהל כדי להסיר אותו, הקפיאו אותו קודם מכל מכשיר מנהל.

1. הריצו בכל מכשיר מנהל:
   - **מסוף:** `sudo cbb freeze NAME`
   - **אפליקציית טלפון או שולחן עבודה:** פתחו את מחשב המנהל ב**מסך הבית**, בחרו **הקפאה** ואשרו.

   **תוצאה:** שום דבר שהמנהל המוקפא חותם עליו אינו נחשב מאותו רגע, וכל מכשיר אחר דוחה את החיבורים שלו. מנהל מוקפא אינו יכול להקפיא את המכשיר הראשי או טלפון מנהל.

2. ברגע שיש לכם את המכשיר הראשי או טלפון מנהל, הסירו את המחשב המוקפא (שלב 1).

אם שני מחשבי מנהל מקפיאים זה את זה לפני שהם יודעים על ההקפאה של האחר, שניהם נשארים מוקפאים עד שהמכשיר הראשי מחליט: הריצו `sudo cbb unfreeze NAME` או `sudo cbb remove NAME` במחשב הראשי, או בחרו **הפשרה** או **הסרה** בטלפון הראשי.

## 3. אם זה היה המכשיר הראשי: העבירו את הקבוצה

**המכשיר הראשי** מחזיק את המפתח הראשי של הקבוצה. אם המכשיר הראשי אבד או נשבר, העבירו את הקבוצה למכשיר אחר שכבר נמצא בקבוצה בעזרת **מפתח השחזור** של הקבוצה — דף השחזור המודפס או ה-YubiKey ששמרתם כשיצרתם את הקבוצה.

איש אינו יכול להעביר את הקבוצה בלי מפתח השחזור, אפילו לא מנהל. אם אין לכם את מפתח השחזור, אי אפשר להעביר את הקבוצה: עזבו את הקבוצה הישנה בכל אחד מהמכשירים שנותרו (`sudo cbb leave` או **עזיבת הקבוצה** באפליקציה), צרו קבוצה חדשה וצמדו את המכשירים שלכם מחדש.

### העברת הקבוצה לטלפון בקבוצה

1. בטלפון אחר שכבר נמצא בקבוצה שלכם, פתחו את **CBB** ועברו אל **הגדרות > להעביר את הקבוצה לטלפון הזה**.
2. ספקו את מפתח השחזור:
   - **דף השחזור:** סרקו את קוד ה-QR שעל הדף או הקלידו את הטקסט שלו.
   - **YubiKey:** הצמידו את ה-YubiKey לטלפון (NFC) או חברו אותו ליציאת ה-USB-C (ב-Aurora OS, ‏USB-C בלבד), הזינו את ה-PIN שלו וגעו ב-YubiKey כשתתבקשו.
3. עברו על רשימת המכשירים בקבוצה ובטלו את הסימון של המכשיר הראשי שאבד (ושל כל מכשיר אחר שתרצו להוציא).
4. הקישו על **להפוך את הטלפון הזה למכשיר הראשי** ואשרו באמצעות פנים, טביעת אצבע, קוד גישה או (ב-Aurora OS) קוד ה-PIN של המנהל.

**תוצאה:** הטלפון הזה הופך מיד למכשיר הראשי של הקבוצה עם מפתח ראשי חדש. כל מכשיר מסומן נשאר בקבוצה ועוקב אחר המכשיר הראשי החדש ברגע שהוא מתחבר; כל מכשיר שאינו מסומן מוצא מהקבוצה ונדחה על ידה.

### העברת הקבוצה למחשב בקבוצה

1. במחשב אחר בקבוצה שלכם, פתחו מסוף (כמנהל מערכת ב-Windows) והריצו:
   - **עם דף השחזור:**

     ```sh
     sudo cbb recovery -leave LOST-DEVICE
     ```

   - **עם YubiKey** (דורש `pcscd` ב-Linux וב-FreeBSD):

     ```sh
     sudo cbb recovery -yubikey -leave LOST-DEVICE
     ```

   חזרו על `-leave NAME` לכל מכשיר שתרצו להוציא. תוכלו להתחיל את התהליך הזה גם באפליקציית ה-Mac או באפליקציית מגש המערכת באמצעות **להעביר את הקבוצה ל-Mac הזה** / **להעביר את הקבוצה למחשב הזה**.
2. עברו על מי נשאר ומי עוזב, אשרו, ואז הקלידו את מפתח השחזור מהדף בקלט התקני (או הזינו את ה-PIN של ה-YubiKey וגעו בו כשהוא מהבהב).

**תוצאה:** שירות המחשב מופעל מחדש כמכשיר הראשי החדש של הקבוצה, שומר כל מכשיר שברשימה ודוחה כל מכשיר שהוצא. המחשב מוחק את מפתח השחזור אחרי השינוי.

## 4. כבו תכונות מרחוק במידת הצורך

הסרת המכשיר שאבד עוצרת אותו מלפעול בקבוצה שלכם. אם אינכם יכולים להסיר אותו מיד, או שתרצו לנעול מיד את שאר המכשירים שלכם, כל מנהל יכול לכבות את התכונות האלה ממכשיר אחר:

| תכונה | פקודה במחשב מנהל | באפליקציית טלפון מנהל |
|---|---|---|
| [הדבקה מרחוק](remote-paste.md) | `sudo cbb paste-receive off -on DEVICE` (או `-all`) | פתחו את דף המכשיר וכבו הדבקה מרחוק |
| [פעולות מהירות](quick-actions.md) | `sudo cbb action off -on DEVICE` (או `-all`) | פתחו את דף המכשיר והקישו על **כיבוי הכול** |
| [סנכרון מחוץ לבית](away-from-home.md) | `sudo cbb global off -on DEVICE` | פתחו את דף המכשיר וכבו סנכרון מחוץ לבית |

**תוצאה:** המכשירים המושפעים משביתים את התכונות האלה מיד. רק המשתמש של כל מכשיר עצמו יכול להפעיל אותן שוב מקומית.

## למה גנב יכול לגשת

מה שמישהו שגנב את המכשיר שלכם יכול להשיג תלוי במקום שבו המכשיר שומר את המפתחות שלו (ראו [מפתחות ואימות](keys.md)):

- **מפתחות בחומרה** (טלפונים עם שבב אבטחה, מחשבי Mac עם Apple silicon או שבב T2, ומחשבי Linux או Windows עם TPM 2.0): אי אפשר להעתיק את המפתחות מהמכשיר. בטלפונים, המפתחות של המכשיר הראשי והמנהלים חותמים רק אחרי פנים, טביעת אצבע, קוד גישה או (ב-Aurora OS) קוד ה-PIN של המנהל.
- **מפתחות בקבצים** (מחשבי Intel Mac בלי שבב T2, מחשבי Linux ו-Windows בלי TPM,‏ FreeBSD, מכשירים קטנים, טלפוני Aurora OS 4 ו-Sailfish OS והתקנות Linux ללא root): כל מי שיכול לקרוא את הדיסק יכול להעתיק את קובצי המפתח ולהתחזות לאותו מכשיר עד שתסירו אותו. השאירו הצפנת דיסק מלאה מופעלת (FileVault,‏ BitLocker או LUKS).

Connect Beyond Borders לא שומר היסטוריית לוח. העתקות רגילות פגות לאחר משך חיי ההעתקה של הקבוצה (5 דקות כברירת מחדל), וסודות נשארים בזיכרון בלבד ופגים לאחר 60 שניות כברירת מחדל.
