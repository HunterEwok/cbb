# מחוץ לבית

למי שרוצה שהמכשירים שלו ימשיכו להסתנכרן גם מחוץ לרשת הביתית. בדף הזה תגדירו מחשב בבית כ**רכזת**, תפעילו סנכרון מחוץ לבית במכשירים האחרים שלכם, תגדירו לפי הצורך **מעביר** או **ממסר עיוור**, ותזמינו מכשירים שאינם בבית.

בבית, המכשירים שלכם מתחברים ישירות ברשת המקומית. מחוץ לבית, הם מגיעים לרכזת בבית דרך מנהרת ה-WireGuard המוצפנת של הקבוצה עצמה. כדי להבין איך רכזות, מעבירים וממסרים עיוורים עובדים, ראו [איך זה עובד](how-it-works.md#away-from-home-the-hub). למה שכל שרת יכול לראות, ראו [פרטיות: מי רואה מה](privacy.md).

הסנכרון מחוץ לבית נשאר כבוי עד שתפעילו אותו ברכזת ובכל מכשיר שזקוק לו. הגדירו אותו **כשכל המכשירים נמצאים ברשת הביתית שלכם**, משום שהמכשירים מחליפים מפתחות מנהרה מקומית עם הרכזת.

## 1. בחרו את הרכזת

**רכזת** היא מחשב, נתב או לוח קטן בבית (Linux,‏ macOS,‏ Windows,‏ FreeBSD,‏ OpenWrt או OPNsense). טלפון, שעון או [התקנת Linux ללא root](install.md#without-sudo-rootless) לעולם אינם רכזת. בחרו מכשיר שדולק רוב הזמן, כמו שרת ביתי, NAS, נתב או Raspberry Pi. כל עוד הרכזת כבויה, הסנכרון מחוץ לבית מושהה, בזמן שהמכשירים שבבית ממשיכים להסתנכרן ישירות.

בחרו איזה סוג רכזת אתם רוצים:

- **רכזת שקוראת העתקות:** **המכשיר הראשי** של הקבוצה שלכם (אם הוא מחשב) או מחשב **מנהל**. המכשירים אוטמים עבורה העתקות כמו לכל מכשיר קורא אחר, ו[רמת המפתחות](keys.md#the-three-levels) של הקבוצה חלה על המפתחות שלה.
- **רכזת שרק מעבירה העתקות הלאה:** כל מחשב רגיל או לוח קטן בקבוצה שלכם. המכשירים אוטמים העתקות מקצה לקצה מעבר לה, כך שהיא אינה קוראת העתקות, אינה יוצרת העתקות משלה, אינה מקבלת הדבקות מרחוק או פעולות מהירות ואינה זקוקה לשבב אבטחה בחומרה. רק המכשיר הראשי של הקבוצה יכול למנות רכזת שרק מעבירה העתקות הלאה.

לקבוצה יכולות להיות כמה רכזות בסדר עדיפות; רק הרכזת המחוברת בעלת העדיפות הגבוהה ביותר משרתת בכל רגע. כדי לקבוע את הסדר מהמכשיר הראשי (או ממחשב מנהל שיכול להיות רכזת), הריצו `sudo cbb global hubs NAME...`.

## 2. הפעילו אותו ברכזת

אפשר להגדיר את הרכזת מאפליקציית שולחן עבודה, מטלפון מנהל או ממסוף.

### באמצעות אפליקציית ה-Mac או אפליקציית המגש

1. פתחו את **CBB** במחשב שאתם רוצים להשתמש בו כרכזת.
2. פתחו את דף המכשיר של המחשב הזה עצמו ולחצו על **הפיכה לרכזת**.
3. אם תתבקשו, בחרו **רכזת שקוראת את ההעתקות** או **רכזת שרק מעבירה אותן**, ואשרו את הפעלת הסנכרון מחוץ לבית.

**תוצאה:** האפליקציה מפעילה את הסנכרון מחוץ לבית עבור המחשב הזה ומגדירה אותו כרכזת באמצעות המעביר של הפרויקט ב-`cbb.tools`, כך שאין צורך לפתוח יציאה בנתב שלכם.

### באמצעות טלפון מנהל

1. במחשב שאתם רוצים להפוך לרכזת, הפעילו קודם את הסנכרון מחוץ לבית (`sudo cbb global on`, או הפעילו את **בכל מקום** באפליקציית שולחן העבודה).
2. בטלפון שלכם, פתחו את **CBB** והקישו על המחשב ב**מסך הבית**.
3. אם המחשב עדיין אינו מנהל (ואתם רוצים רכזת שקוראת העתקות), הקישו על **הפיכה למנהל** ואשרו.
4. הקישו על **הפיכה לרכזת** ואשרו בפנים, בטביעת אצבע, בקוד גישה או (ב-Aurora OS) בקוד ה-PIN של המנהל.

**תוצאה:** המחשב הופך לרכזת דרך המעביר של הפרויקט ב-`cbb.tools`.

### באמצעות מסוף

ב-Linux, ב-macOS או ב-FreeBSD, הריצו את הפקודות האלה במחשב הרכזת (ב-Windows, השמיטו את `sudo` והשתמשו במסוף מנהל):

1. הפעילו את הסנכרון מחוץ לבית:

   ```sh
   sudo cbb global on
   ```

   אם המחשב שומר את המפתחות שלו בקבצים, קראו את האזהרה והקלידו `yes`.

   **תוצאה:** השירות מתיר חיבורי מנהרה יוצאים אל שרתי הקבוצה שלכם ומשאיר את כל שאר היעדים באינטרנט חסומים.

2. הפכו את המחשב לרכזת. בחרו אחת מהאפשרויות הבאות:
   - **חיבור ישיר עם כתובת ביתית ציבורית** (IPv4,‏ IPv6 או שם דומיין המצביע אל הבית שלכם):

     ```sh
     sudo cbb global hub 203.0.113.7:8764
     ```

   - **דרך מעביר** (כשאין לבית שלכם כתובת ציבורית או כשאתם לא רוצים לפתוח יציאה בנתב):

     ```sh
     sudo cbb global hub
     ```

   **תוצאה:** אם נתתם כתובת ביתית, `cbb global hub` מפרט את כלל ה-UDP בחומת האש שהוא צריך ושואל לפני שהוא מוסיף אותו. בלי כתובות, הרכזת נרשמת אצל המעביר של הפרויקט ב-`cbb.tools`.

3. אם נתתם כתובת ביתית ציבורית והרכזת שלכם נמצאת מאחורי נתב, פתחו את הגדרות הנתב והעבירו את **יציאת UDP 8764** (או היציאה שהגדרתם עם `-port`) אל כתובת ה-IP המקומית של הרכזת. חפשו **Port Forwarding** או **Virtual Server** בהגדרות הנתב שלכם.

   ב**נתב OpenWrt** שמשמש כרכזת, הריצו את הפקודות שלמעלה כ-`root` בלי `sudo`. אין צורך בהעברת יציאות אלא אם הנתב נמצא מאחורי נתב אחר (double NAT): כשאתם מאשרים את שאלת חומת האש, Connect Beyond Borders מוסיף את כלל ה-UDP מ-WAN לכללי חומת האש של השירות עצמו בלי לערוך את `/etc/config/firewall`.

כדי להפוך מחשב אחר לרכזת שרק מעבירה העתקות הלאה מתוך המכשיר הראשי (שנקרא *root* בכלי שורת הפקודה), הפעילו קודם את הסנכרון מחוץ לבית באותו מחשב, ואז הריצו במכשיר הראשי:

```sh
sudo cbb global hub -on DEVICE -forward-only
```

## 3. הפעילו אותו במכשירים האחרים

בזמן שכל המכשירים נמצאים ברשת הביתית שלכם והרכזת פועלת:

- **מחשבים ומכשירים קטנים:** הריצו `sudo cbb global on` (במסוף מנהל בלי `sudo` ב-Windows), או הפעילו את **בכל מקום** באפליקציית ה-Mac או באפליקציית המגש. שימו לב שגרסאות נתבים של MIPS מסנכרנות ברשת הביתית בלבד; ראו [מכשירים, יציאות וקבצים](../reference/devices.md).
- **טלפונים:** פתחו את **CBB** והפעילו את **בכל מקום** (מתג הגלובוס) מתוך **מסך הבית**, ואז השאירו את האפליקציה פתוחה לזמן קצר בבית כדי שתחליף מפתחות מנהרה עם הרכזת. טלפוני Android ממשיכים להסתנכרן מחוץ לבית ברקע; טלפוני iPhone,‏ Aurora OS ו-HarmonyOS מסתנכרנים בזמן שהאפליקציה פתוחה.

**תוצאה:** כל מכשיר מקבל את הצעת המנהרה של הרכזת ומחליף איתה מפתחות מנהרה.

## 4. בדקו זאת

1. בכל מחשב, הריצו:

   ```sh
   cbb global
   ```

   **תוצאה:** הפלט מראה אם הסנכרון מחוץ לבית פועל, איזה מכשיר הוא הרכזת, אם המנהרה מחוברת, וכל שגיאה אם יש כזו.

2. הוציאו טלפון או מחשב נייד מה-Wi-Fi הביתי שלכם (לדוגמה, העבירו טלפון לנתונים סלולריים) והעתיקו שורת טקסט.

   **תוצאה:** הטקסט שהועתק מגיע למכשירים שלכם בבית.

אם המנהרה לא מתחברת, בדקו את העברת יציאת ה-UDP ואת הכתובת הציבורית בנתב שלכם, או ראו [פתרון בעיות: סנכרון מחוץ לבית](troubleshooting.md#sync-away-from-home).

אם הכתובת הציבורית של הבית שלכם משתנה מאוחר יותר, הרכזת משתפת את הכתובת החדשה בפעם הבאה שהמכשירים שלכם נפגשים. כש-`cbb global` או `cbb status` מדווחים שכלל הרשת היוצא של המערכת מפגר מאחור, הריצו `sudo cbb global allow` באותו מחשב כדי לעדכן את הכלל.

## 5. כשהאינטרנט לא יכול להגיע לבית שלכם: מעביר

ספקי אינטרנט רבים מציבים בתים מאחורי carrier-grade NAT (כתובת IP ציבורית משותפת), מה שחוסם חיבורים נכנסים גם עם העברת יציאות. **מעביר** פותר זאת: הרכזת שלכם פותחת חיבור יוצא אל המעביר, ומכשירים מחוץ לבית שולחים דרכו חבילות מנהרה מוצפנות אל הרכזת. אין צורך לפתוח יציאות בנתב, והמעביר אינו מחזיק שום מפתחות של הקבוצה.

בחרו אחת משתי האפשרויות ברכזת שלכם:

- **שימוש במעביר של הפרויקט ב-`cbb.tools`:** הריצו `sudo cbb global hub` בלי כתובת, או הוסיפו `-forwarder default` לצד הכתובות הציבוריות של הרכזת שלכם:

  ```sh
  sudo cbb global hub -forwarder default 203.0.113.7:8764
  ```

- **שימוש במעביר משלכם:** הריצו מעביר בכל שרת עם כתובת ציבורית ([הפעלת שרתים משלכם](../admin/self-hosting.md#a-forwarder)), ואז העבירו את הכתובת והמפתח שלו לרכזת:

  ```sh
  sudo cbb global hub -forwarder 198.51.100.9:8764 -forwarder-key KEY
  ```

**תוצאה:** כשלרכזת יש גם כתובות ישירות וגם מעביר, מכשירים מחוץ לבית מנסים קודם את הכתובות הישירות ועוברים אל המעביר אם החיבורים הישירים נכשלים.

## 6. רשתות שחוסמות VPN

בתי מלון, משרדים, מפעילות סלולר וכמה מדינות חוסמים את WireGuard. כברירת מחדל, הרכזת מסווה את המנהרה שלה באמצעות **AmneziaWG** ו-(בעת שימוש במעביר שתומך בכך) **VLESS** על גבי HTTPS. כדי להגדיר או להתאים את הסוואת המנהרה, ראו [רשתות שחוסמות VPN](blocked-networks.md).

## מחשב שאינו בבית: הזמנה

ברגע שסנכרון מחוץ לבית עובד דרך רכזת, אפשר להזמין מחשב או טלפון שאינם נמצאים ברשת הביתית שלכם. הזמנה עובדת פעם אחת ותקפה לשעה אחת כברירת מחדל (עד 24 שעות עם `-for`).

### הזמנת מכשיר וקבלתו

1. במכשיר הראשי או במנהל, צרו הזמנה:
   - **במסוף במחשב מנהל:** הריצו `sudo cbb invite` למחשב (כותב את `cbb.cbbinvite`), או `sudo cbb invite -phone` לטלפון (מדפיס קוד QR). השאירו את הפקודה רצה עד שהמכשיר החדש מצטרף.
   - **באפליקציית טלפון או שולחן עבודה:** הקישו **+** ב**מסך הבית** (או בחרו **הוספת מכשיר > המכשיר רחוק? שלחו הזמנה** באפליקציית שולחן עבודה) ועקבו אחר ההנחיות.
2. שלחו את קובץ ההזמנה, הטקסט (`cbb://join#...`) או קוד ה-QR אל המכשיר החדש בערוץ שאתם סומכים עליו. כל מי שמחזיק בהזמנה שלא נוצלה יכול לבקש להצטרף, אם כי אתם עדיין מאשרים את הקבלה על ידי התאמת טביעות האצבע של המפתחות.
3. במכשיר החדש, השתמשו בהזמנה:
   - **במחשב (מסוף):** הריצו `sudo cbb pair -invite cbb.cbbinvite` (או `sudo cbb pair -invite -` והדביקו את טקסט ה-`cbb://join#...` בקלט התקני).
   - **במחשב (אפליקציית שולחן עבודה):** בחרו **הצטרפות בהזמנה** והדביקו את טקסט ההזמנה.
   - **בטלפון:** פתחו את **CBB**, הקישו על **הצטרפות בהזמנה**, וסרקו את קוד ה-QR, הדביקו את טקסט ההזמנה או פתחו את קובץ ההזמנה.

   **תוצאה:** שני המכשירים מציגים את טביעת האצבע של המפתח של המכשיר החדש.

4. השוו את טביעת האצבע של המפתח שמוצגת במכשיר המזמין לטביעת האצבע שמוצגת במכשיר החדש. הקלידו `yes` (או הקישו **קבלה**) רק אם הן תואמות בדיוק.

**תוצאה:** המכשיר החדש מצטרף לקבוצה שלכם ומתחיל להסתנכרן דרך הרכזת. `cbb invite` מוחק את קובץ ההזמנה הזמני כשהוא מסיים.

כדי להוסיף במקום זאת מחשב מרשת אחרת דרך SSH או ה-VPN שלכם, ראו [בלי האפליקציה: הצטרפות מרשת אחרת](without-app.md#joining-from-another-network).

## אין מחשב לרכזת

טלפון לעולם אינו רכזת. אם אין לקבוצה שלכם מחשב, נתב או לוח קטן שישמש כרכזת (לדוגמה, קבוצה של טלפונים בלבד), המכשירים שלכם יכולים להיפגש במקום זאת ב**ממסר עיוור**. שני המכשירים חייבים להיות מחוברים בו-זמנית כדי להחליף העתקה.

ממסר עיוור אינו יכול לקרוא את הלוח שלכם, אבל הוא רואה אילו כינויים זמניים של מכשירים מחוברים יחד, את כתובות ה-IP שלהם, התזמון ונפח התעבורה. רק **המכשיר הראשי** של הקבוצה מפעיל או מכבה ממסר עיוור עבור הקבוצה, ורק אחרי שאתם מסכימים למה שהממסר רואה.

### הפעלת ממסר עיוור

- **בטלפון (מכשיר ראשי):** פתחו **הגדרות**, הפעילו **הגדרות מתקדמות**, הקישו על **ממסר עיוור**, ובחרו את הממסר של הפרויקט או הזינו את הכתובת והמפתח של הממסר שלכם. אשרו את ההודעה.
- **במחשב (מכשיר ראשי):**
  - שימוש בממסר הפתוח של הפרויקט ב-`cbb.tools:8765`:

    ```sh
    sudo cbb global relay default
    ```

  - שימוש בממסר משלכם ([הפעלת שרתים משלכם](../admin/self-hosting.md#a-blind-relay)):

    ```sh
    sudo cbb global relay 198.51.100.9:8764 -key KEY
    ```

  קראו מה הממסר יכול לראות והקלידו `yes`.

**תוצאה:** הגדרות הקבוצה שלכם מציינות את הממסר, ומכשירים שבהם **בכל מקום** פועל נפגשים שם.

כדי להפסיק להשתמש בממסר עיוור, הריצו `sudo cbb global relay off` במחשב הראשי, או פתחו **הגדרות > הגדרות מתקדמות > ממסר עיוור** בטלפון הראשי והקישו על **עזיבת הממסר**.

## כיבוי

### להפסיק שמחשב ישמש כרכזת

כדי שמחשב יפסיק לשמש כרכזת בזמן שהסנכרון מחוץ לבית נשאר מופעל בו:

- **באפליקציית ה-Mac או באפליקציית המגש:** פתחו את דף המכשיר של הרכזת ולחצו על **הפסקת התפקיד כרכזת**.
- **במסוף:** הריצו `sudo cbb global hub off` ברכזת, או `sudo cbb global hub off -on NAME` ממחשב מנהל.

**תוצאה:** מכשירים מחוברים מחוץ לבית עוברים אוטומטית לרכזת הבאה של הקבוצה. אם אין לקבוצה רכזת אחרת, Connect Beyond Borders מבקש אישור לפני ההפסקה (העבירו `-yes` בסקריפטים כדי לאשר), משום שמכשירים מחוץ לבית מפסיקים להסתנכרן עד שתוגדר רכזת אחרת.

### כיבוי הסנכרון מחוץ לבית במכשיר

- **במחשב:** הריצו `sudo cbb global off` (ב-Windows, ‏`cbb global off` במסוף מנהל), או כבו את **בכל מקום** באפליקציית שולחן העבודה.
- **בטלפון:** כבו את **בכל מקום** ב**מסך הבית**.

**תוצאה:** המכשיר שוכח את מפתחות המנהרה שלו ומפסיק להסתנכרן מחוץ לבית. ב-Linux וב-Windows, ‏`cbb global off` מסיר גם את שרתי הקבוצה מכלל הרשת היוצא של המערכת. מכיוון שמפתחות מנהרה חדשים מוחלפים עם הרכזת ברשת הביתית שלכם, מכשיר שמכבה את הסנכרון מחוץ לבית בזמן שהוא מחוץ לבית יחדש את הסנכרון מחוץ לבית רק אחרי שיתחבר שוב בבית.
