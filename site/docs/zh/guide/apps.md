# 应用

写给在手机、平板电脑、手表、电视或电脑上使用 Connect Beyond Borders 应用的人。在电脑、路由器和服务器上安装后台服务见[安装](install.md)。工程细节见[应用规格说明](../apps.md)。

Connect Beyond Borders 为手机、平板电脑、手表、Android TV 和桌面电脑提供原生应用。手机应用可以保管群组的主密钥并管理设备；桌面应用则为该电脑上正在运行的后台服务提供窗口和菜单图标。

## 可用的应用

| 应用 | 获取方式 | 说明 |
|---|---|---|
| **Android**（Android 10 或更高版本） | 每个 [GitHub 发布版本](https://github.com/HunterEwok/cbb/releases)中的 `cbb-X.Y.Z.apk` | 包含 Wear OS 手表支持、自动更新和推送通知 |
| **不含 Google 服务的 Android**（F-Droid 版本） | 每个 [GitHub 发布版本](https://github.com/HunterEwok/cbb/releases)中的 `cbb-fdroid-X.Y.Z.apk` | 不含 Google Play 服务的可复现构建；应用关闭时的通知使用 UnifiedPush，不包含 Wear OS |
| **Android TV、Google TV 和 Fire OS** | 同一个 Android APK（`cbb-X.Y.Z.apk` 或 `cbb-fdroid-X.Y.Z.apk`） | 方向键界面；以仅接收成员身份加入 |
| **iPhone 和 iPad**（iOS 17 或更高版本） | TestFlight（受邀后）或用 Xcode 从 `apps/ios` 构建 | 控制中心开关需要 iOS 18 或更高版本 |
| **Apple Watch**（watchOS 10 或更高版本） | 随 iPhone 应用一起提供 | 通过配对的 iPhone 工作 |
| **Wear OS**（Wear OS 3 或更高版本） | 每个 [GitHub 发布版本](https://github.com/HunterEwok/cbb/releases)中的 `cbb-wear-X.Y.Z.apk`（使用 `adb install` 安装） | 通过配对的 Android 手机（完整版）工作 |
| **Aurora OS 和 Sailfish OS** | 从 `apps/silica` 构建（面向 Aurora OS 5.1.5 提供已签名 RPM 包） | 在 Aurora 5 上将管理员密钥保存在受应用 PIN 保护的 OP-TEE 中；在 Aurora 4 和 Sailfish OS 上将密钥保存在文件中 |
| **HarmonyOS**（HarmonyOS 5 或更高版本，手机、平板电脑和手表） | 从 `apps/harmony` 构建 | 将密钥保存在 HUKS 中；手表应用通过配对的 HarmonyOS 手机工作 |
| **Mac 应用**（macOS 14 或更高版本） | 每个 [GitHub 发布版本](https://github.com/HunterEwok/cbb/releases)中的 `cbb-X.Y.Z.pkg` | 随后台服务一起安装的菜单栏应用 |
| **Linux 和 Windows 托盘应用** | 包含在 Windows 和 Linux（x86-64、ARM64）的发布归档包中 | 随服务自动安装（在 Linux 上需要 GTK 4 和 WebKitGTK 6.0） |

关于哪些应用已在真机上测试、哪些仅在模拟器和 CI 中测试，见[平台对等](../parity.md#on-real-devices)。

## 手机

### 创建或加入群组

在未配置群组时打开应用，你有三个选择：

- **创建群组**：应用会在手机的安全硬件中（iPhone 上的 Secure Enclave、Android 上的 Keystore、Aurora OS 5 上的 OP-TEE，或 HarmonyOS 上的 HUKS）创建群组的主密钥，并要求你通过面容、指纹、密码或（在 Aurora OS 上）应用自己的 PIN 确认。随后它会显示一次群组的**恢复密钥**，并提供**写在纸上**、**写入 YubiKey**（在支持 NFC 或 USB-C 的设备上），或两者都选。保存后，应用会打开**添加设备**配对窗口。
- **加入群组**：扫描家庭网络中现有手机或管理员电脑的**添加设备**界面显示的二维码，或手动输入其六位数字。手机始终以成员身份加入；主设备之后可以将其设为管理员。
- **通过邀请加入**：扫描邀请的二维码、粘贴其文本或打开邀请文件，即可在离家时通过群组的中心节点加入群组。

要在主设备或管理员手机的**主页**添加设备，请点按 **+**，然后选择**添加设备**（显示二维码和六位数字，有效五分钟）或**发送邀请**（用于离家的设备）。

### 日常同步

**主页**顶部显示当前在线的设备数量以及两个开关：

- **同步**（房子图标）：轻点可关闭或开启这部手机的同步。按住可选择暂停同步 15 分钟、1 小时、8 小时，或直到你重新开启。同步关闭期间，剪贴板仅留在这部手机上。
- **随处**（地球图标）：开启或关闭离家同步。**同步**关闭期间，**随处**会暂停，直到你重新开启**同步**。

在标题栏下方，**主页**会显示群组通知、最近收到的副本（附带**复制**按钮，可重新放回剪贴板），以及以磁贴或列表形式展示的群组设备。每个设备磁贴都用圆点表示在线状态，在其详情页上也会以文字显示。

复制和粘贴的工作方式取决于手机的操作系统：

- **打开应用（所有手机）**：当你打开 **CBB** 或从后台切回它时，如果你复制了新内容，应用会发送剪贴板；否则会获取群组的最新副本。应用停留在屏幕上期间，收到的副本会自动进入你的剪贴板。
- **iPhone**：iOS 只允许应用在前台读取剪贴板。首次设置时，请在 iOS 设置中允许**从其他 App 粘贴**，这样 iOS 就不会每次询问（如果拒绝，**主页**上会出现一个系统粘贴按钮）。在应用之外，你可以用**同步剪贴板**快捷指令（绑定到轻点背面或操作按钮）或主屏幕上的**同步剪贴板**小组件，通过一个手势将剪贴板与群组互换。在 iOS 18 或更高版本中，可用控制中心的**同步**控件开关同步。**共享 → Connect Beyond Borders** 会将文本、链接、图片或文件（合计最多 50 MB）加入队列，并在你下次打开 **CBB** 时发送。在 iOS 17 或更高版本上，灵动岛和锁屏界面会显示正在进行的配对、隧道连接时长和同步确认（绝不显示剪贴板文本）。
- **Android**：电脑上的副本会在后台自动到达手机剪贴板。如果想让手机上复制的内容也自动发送，请在**设置**中开启**剪贴板同步**（一项无障碍服务；在 Android 13 或更高版本上，通过 APK 安装的应用需先在应用信息中开启**允许受限设置**）。不开启**剪贴板同步**时，也可以通过以下方式一键发送：
  - 常驻 CBB 通知中的**发送**
  - 主屏幕上的**发送剪贴板**小组件
  - **分享 → Connect Beyond Borders** 或文本选择菜单（文件最多 100 MB）
  - **cbb send** 启动器入口（可配合 Pixel 轻点背面或三星 Back-Tap 使用）
  - Android 快捷设置中的**同步**磁贴可切换同步开关（长按可打开应用）。
- **Aurora OS 和 HarmonyOS**：打开应用即可按上述方式同步。**分享 → Connect Beyond Borders** 可发送文本、图片和文件（合计最多 50 MB）。Aurora OS 会在应用封面上显示状态和快捷同步操作；HarmonyOS 提供主屏幕小组件和实况窗状态显示。

关于图片、格式化文本以及收到文件的保存位置，见[图片、文件和格式化文本](images-and-files.md)。

### 整理设备

你可以自定义设备的排列顺序，并将它们分组到**合集**中（例如“办公室”或“家”）。你的布局和合集仅保存在该设备上，绝不会与群组或任何服务器共享。

- 在**主页**菜单中切换**磁贴**和**列表**视图（在平板电脑和桌面上还提供**轨道**视图）。
- 从菜单启动**整理设备**（或长按某个磁贴）来拖动排序或将设备拖入合集，或使用**恢复群组的顺序**重置。
- 当群组超过 12 台设备时，**主页**会显示搜索栏以及**在线** / **需要关注**筛选器。

### 管理设备

在**主页**点按任意设备，即可查看其状态、角色、操作系统和 Connect Beyond Borders 版本；点按**更多**可查看额外的技术详情（设备类型、MAC 地址、设备 ID）。

如果你的手机是主设备或管理员，在设备页面上你可以执行以下操作：

- **同步**或**静音 / 取消静音**：开启或关闭已连接电脑的同步，或将任意设备静音 15 分钟、1 小时、8 小时，或直到管理员取消静音（也可以直接从设备磁贴的角落按钮静音）。
- **粘贴**：将文本、图片或文件直接发送到已开启远程粘贴的电脑上当前获得焦点的应用中（[远程粘贴](remote-paste.md)）。
- **快捷操作**：运行允许的操作，例如锁定电脑或让电脑进入睡眠（[快捷操作](quick-actions.md)）。
- **重命名**：在整个群组中更改该设备的名称。
- **设为管理员**（仅限主设备）：让另一部手机或电脑可以添加和移除设备。配备 Apple 芯片或 T2 芯片的 Mac 将管理员密钥保存在 Secure Enclave 中，带 TPM 的 Linux 和 Windows 电脑则保存在 TPM 中。如果电脑把密钥保存在文件中，应用在提升其权限前会提醒你（[密钥与认证](keys.md#the-three-levels)）。
- **设为中心节点**：将管理员电脑设为用于离家同步的中心节点（手机从不担任中心节点）。
- **冻结 / 解冻**：冻结被盗的管理员电脑，使其签署的任何内容在主设备解冻或移除它之前均无效。
- **移除**：立即将设备从群组中移除。

每项更改群组的操作都需要验证你的面容、指纹、密码，或（在 Aurora OS 上）你的管理员 PIN。在 Aurora OS 5 上，PIN 由手机的安全元件强制验证，连续七次输错 PIN 会永久锁定管理员密钥（手机仍作为成员留在群组中）。在主设备上，应用每 30 天还会请求续期一次群组用于离家同步的服务器凭据。

### 第二部手机和丢失的手机

- **添加第二部手机**：在主手机上点按 **+**，然后在第二部手机上点按**加入群组**并扫描二维码。第二部手机会作为成员加入。在主手机的**主页**上打开它并点按**设为管理员**，这样你就有了第二部管理员手机。
- **如果手机丢失**：在另一部管理员手机的**主页**上将其移除。你的其他设备会留在群组中。如果丢失的手机是**主设备**，请在群组中的另一台设备上打开**设置 > 把群组移到这部手机**，提供恢复密钥（恢复纸页或 YubiKey），并且不要勾选丢失的手机，使群组拒绝它。详见[如果设备丢失](lost-device.md)。

### 设置

基本设置显示在**设置**页面的最前面：

- **外观和主题**：选择**系统**、**深色**或**浅色**外观，以及**十一种主题**之一（黑板、蓝图、精确、玻璃、柔和、瑞士、硬件、装饰艺术、液态玻璃、终端和复古）。Android 12 及更高版本还提供 **Material You**（跟随壁纸配色）；Aurora OS 跟随系统氛围。
- **语言**：跟随系统语言，或在八种语言中任选其一：英语、简体中文、西班牙语、俄语、阿拉伯语、斯瓦希里语、希伯来语和印地语。阿拉伯语和希伯来语采用从右到左的界面布局。
- **通知**：分别开启或关闭关于设备加入或离开、管理员变更、冻结、主设备变更以及中心节点连接问题的通知开关。在 iPhone 和 Android 上，**应用关闭时通知我**可启用加密封装的推送通知，在不泄露副本内容的前提下唤醒手机。
- **恢复密钥**（在主设备上）或**把群组移到这部手机**（在其他手机上）。
- **离开群组**：删除这部手机的密钥和群组数据，同时保留你的偏好设置。
- **关于与错误详情**：连续点按**版本**行七次可显示**显示错误详情**开关，开启后会在简短错误消息下方显示底层原因，方便报告问题。在 Android（完整发布版 APK）上，**关于**中还包含更新检查和自动更新设置。

打开**高级设置**即可访问：

- **为什么不同步**：用通俗语言说明此设备未同步的原因以及下一步该做什么。
- **离家**和**盲中继**：显示隧道状态，并允许主设备为没有中心节点的群组配置盲中继（[离家可用](away-from-home.md)）。
- **群组**（仅限管理员）：设置**副本保留时长**（1 分钟到 1 小时；默认 5 分钟）、**机密的有效期**（5 秒到 1 分钟；默认 60 秒）以及**管理员密钥**（群组的密钥级别，仅在主设备上）。
- **实验室**（Android、Aurora OS 和 HarmonyOS）：蓝牙键盘等实验性功能（[实验室](lab.md)）。

### 平板电脑和折叠屏

在宽屏设备上——iPad、Android 平板电脑、Aurora 平板电脑、HarmonyOS 平板电脑以及展开后的折叠屏——应用会自动切换为分栏视图，带有侧边栏（包含**所有设备**、**需要关注**、合集和设置分区）、**轨道**布局选项、并排显示的设备详情面板、键盘快捷键以及拖放功能（将文本或文件拖到设备磁贴上即可远程粘贴，拖到磁贴旁即可复制到群组）。在窄窗口（例如分屏模式）下，它会自动切回手机布局。

### Android TV

在 Android TV、Google TV 或 Fire OS 上安装 Android APK 会提供支持方向键导航的界面。电视通过输入管理员手机或电脑上的六位配对码加入群组，并以仅接收成员身份运行。

## 手表

**Apple Watch**、**Wear OS** 和 **HarmonyOS 手表**应用均通过配对的手机工作，从不保存你的剪贴板。每款手表应用都会显示：

- 在线设备数量和设备列表（按手机上的合集分组）
- 最近的群组事件
- 手机的**同步**（房子图标）和**随处**（地球图标）开关

## 桌面应用

**Mac 应用**（菜单栏）和 **Linux 与 Windows 托盘应用**（系统托盘）连接到电脑上已在运行的后台服务。无论应用窗口是打开还是关闭，你的剪贴板都会自动同步，因此没有手动发送或获取按钮。

两款桌面应用都提供：

- **系统托盘或菜单栏图标**：显示在线设备数量、**同步**（含暂停时长）、**随处**、**打开 CBB**、**设置**、更新通知和**退出**。
- **主窗口**：以**磁贴**、**列表**或**轨道**形式显示设备，支持自定义排序和**合集**，显示群组通知和提醒，并在列表旁打开设备详情面板。
- **引导与配对**：未加入群组时，提供**创建群组**、**加入群组**、**通过邀请加入**和**把群组移到这台电脑**（使用恢复密钥）。作为管理员加入群组后，**+** 可打开配对窗口（二维码和六位数字）或发送邀请。
- **管理与中心节点控制**：允许你重命名、静音、冻结、移除设备，提升管理员，将电脑配置为中心节点（包括 AmneziaWG、VLESS 和转发器设置），以及调整群组有效期和密钥级别。更改群组的操作会要求输入管理员密码或系统确认（触控 ID、Windows Hello 或 polkit）。
- **macOS 上的远程粘贴**：在**系统设置 > 隐私与安全性 > 辅助功能**中授予辅助功能权限后，Mac 应用打开时即可作为远程粘贴接收端。
- **设置**：外观、全部十一种主题、八种语言、**登录时打开**、**高级设置**（含**为什么不同步**）以及**显示错误详情**（点击版本号七次）。

当出现异常时，见[故障排除](troubleshooting.md)。
