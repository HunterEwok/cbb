# 快速入门

写给首次在家庭网络中用一部手机和一台电脑设置 Connect Beyond Borders 的人。只需四步：安装手机应用、创建群组、添加你的第一台电脑，然后在它们之间共享剪贴板。

Connect Beyond Borders 在你自己的设备之间共享同一个加密剪贴板，不需要云端，也不需要账号。你的设备组成一个**群组**：一组通过签名记录（而非中央服务器）相互信任的设备。创建群组的手机就是它的**主设备**（在命令行工具中称为 *root*）：它保管群组的主密钥并接纳新设备。

![保管群组密钥的手机与 Linux、Mac 和 Windows 电脑相连，使每台设备在你的家庭网络中直接共享同一个剪贴板](../images/group.svg)

如果你想不用手机应用（仅使用电脑）来创建群组，请参见[不用应用](without-app.md)。如果你只有手机，请跳过第 2 和第 3 步：在第一部手机上点按 **+**，然后在每部其他手机上点按**加入群组**并扫描它的二维码（见[两种群组](how-it-works.md#two-kinds-of-group)）。

## 1. 在手机上安装应用并创建群组

本教程以 Android 手机（Android 10 或更高版本）为例。其他手机应用（iPhone、Aurora OS 和 HarmonyOS）见[应用](apps.md)。

1. 在你的 Android 手机上，从[最新 GitHub 发布版本](https://github.com/HunterEwok/cbb/releases/latest)下载 `cbb-X.Y.Z.apk`。
2. 打开下载的文件安装 Connect Beyond Borders。Android 询问时，允许你的浏览器或文件管理器安装应用。
3. 打开 **CBB**，点按**创建群组**。
4. 按提示使用指纹、面容或屏幕锁确认。应用会在手机的安全硬件中创建群组的主密钥。
5. 保存群组的**恢复密钥**，应用只会显示这一次。选择**写在纸上**以打印或保存，选择**写入 YubiKey** 以存入 YubiKey，或者两种都选。请将恢复密钥与设备分开存放：如果这部手机丢失，这是将群组移到另一台主设备的唯一途径（[密钥与认证](keys.md)）。

**你会看到**：关闭恢复密钥界面后，应用会打开**添加设备**界面，显示一个二维码和六位配对码。如果关闭该界面，应用会显示**主页**，其中你的手机显示为在线。

## 2. 在电脑上安装 Connect Beyond Borders

选择一台与手机位于同一家庭网络中的电脑，例如笔记本电脑、台式机或树莓派。

- 在 **Linux** 或 **macOS** 上，打开终端并运行：

  ```sh
  curl -fsSL https://github.com/HunterEwok/cbb/releases/latest/download/get.sh | sudo sh
  ```

  在 macOS 14 或更高版本上，你也可以从[最新 GitHub 发布版本](https://github.com/HunterEwok/cbb/releases/latest)下载并打开 `cbb-X.Y.Z.pkg`，同时安装后台服务和菜单栏应用。

- 在 **Windows** 10（1809 或更高版本）或 11 上，右键选择**以管理员身份运行**打开 PowerShell 并运行：

  ```powershell
  irm https://github.com/HunterEwok/cbb/releases/latest/download/get.ps1 | iex
  ```

安装期间，安装程序会检查下载文件的签名、安装后台服务（`cbb`），并最多询问两个问题：

1. **防火墙规则**（仅在检测到活动防火墙时显示）：回答 `y`，让 Connect Beyond Borders 在你的家庭网络中通信。
2. **自动更新**：回答 `y`，让 Connect Beyond Borders 每天检查已签名的更新并自动安装。

在 Linux 上，注销并重新登录一次，以便你的账户无需 `sudo` 即可运行 `cbb`。在 Windows 上，打开一个新的终端窗口。

**你会看到**：安装程序会报告 Connect Beyond Borders 正在 TCP 端口 8764 上运行，并打印下一步用于加入群组的命令。关于 Homebrew、Docker、路由器及其他选项，见[安装](install.md)。

## 3. 把电脑添加到你的群组

1. 在手机上，确认**添加设备**界面已打开。如果你在**主页**，请点按 **+** 并选择**添加设备**。界面会显示一个二维码和六位数字，并等待五分钟。
2. 在电脑上，使用终端或桌面应用加入：
   - **在终端中（Linux 和 macOS）**：运行 `sudo cbb pair -code`，然后输入手机上显示的六位数字。
   - **在终端中（Windows）**：以管理员身份打开终端，运行 `cbb pair -code`，然后输入这六位数字。
   - **在桌面应用中（Linux 托盘应用、Windows 托盘应用或 macOS 菜单栏应用）**：打开 **CBB**，选择**加入群组**，输入这六位数字，并在提示时输入管理员密码确认。

**你会看到**：电脑会确认已加入群组，手机上的**添加设备**界面也会关闭。在手机的**主页**上，这台电脑会出现在你的设备列表中，并显示为在线。

用同样的方法添加其他电脑：安装 Connect Beyond Borders，在手机上打开**添加设备**，然后运行 `cbb pair -code`（或在桌面应用中使用**加入群组**）。

## 4. 在一台上复制，在另一台上粘贴

试着在电脑上复制一行文本，然后在手机上粘贴。再在手机上复制一段文本并发送到电脑。

- **电脑之间**：在一台电脑上复制，在另一台电脑上直接自动粘贴。
- **电脑到 Android**：电脑上复制的内容会在后台自动到达手机的剪贴板。
- **Android 到电脑**：打开 **CBB** 即可自动发送你复制的内容（如果发送失败，**主页**上会出现**发送我复制的内容**按钮）。无需打开应用，你也可以点按 CBB 通知中的**发送**、点按主屏幕上的**发送剪贴板**小组件、将文本或文件分享到 **Connect Beyond Borders**，或者在应用的**设置**中开启**剪贴板同步**以自动发送复制内容。

要暂停某台设备的同步，使其剪贴板仅留在本机：

- 在手机上，点按**主页**上的**同步**按钮（房子图标）——或者长按它，选择暂停 15 分钟、1 小时、8 小时，或直到你重新开启——或者点按 Android 快捷设置中的**同步**磁贴。
- 在电脑上，运行 `cbb sync off`（用 `cbb sync on` 恢复），或使用桌面应用中的**同步**开关。

各平台应用的全部功能和手势见[应用](apps.md)。

## 推荐的下一步

在你的第一部手机和电脑开始同步后，可以考虑做以下两件事：

- **将常开电脑设为管理员和中心节点**：如果你有一台一直开机的电脑（例如台式机、家用服务器或树莓派），请在主手机的**主页**上打开它，然后点按**设为管理员**。当手机不在手边时，管理员电脑可以添加和移除设备（`sudo cbb pair` 和 `sudo cbb remove NAME`）。如果这台电脑没有硬件安全芯片（TPM 或 Secure Enclave），它的密钥会存放在文件中，应用会在确认前提醒你（[密钥与认证](keys.md#the-three-levels)）。你还可以把常开电脑设为群组的**中心节点**，让你的设备离家后也能继续同步；见[离家可用](away-from-home.md)。
- **添加第二部手机**：在主手机上点按 **+**，然后在第二部手机上点按**加入群组**并扫描二维码。第二部手机会作为成员加入。要让它也能管理设备，请在主手机的**主页**上打开它并点按**设为管理员**。请妥善保管恢复密钥，以防将来需要将群组移到另一台主设备（[如果设备丢失](lost-device.md)）。
