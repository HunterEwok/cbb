# 离家可用

写给希望设备在离开家庭网络后继续同步的人。在本页中，你会把家里的一台电脑设为**中心节点**、在其他设备上开启离家同步、按需配置**转发器**或**盲中继**，并邀请不在家中的设备加入。

在家时，你的设备在本地网络中直接相连。离家时，它们通过群组自己的加密 WireGuard 隧道连回家中的中心节点。中心节点、转发器和盲中继的工作方式见[工作原理](how-it-works.md#away-from-home-the-hub)。每台服务器能看到什么见[隐私：谁能看到什么](privacy.md)。

离家同步默认关闭，直到你在中心节点以及每台需要它的设备上分别开启。请**在所有设备都在家庭网络中时**完成设置，因为设备会在本地与中心节点交换隧道密钥。

## 1. 选择中心节点

**中心节点**是家里的一台电脑、路由器或小型开发板（Linux、macOS、Windows、FreeBSD、OpenWrt 或 OPNsense）。手机、手表或[无 root Linux 安装](install.md#without-sudo-rootless)永远不能担任中心节点。请选择一台大多数时间保持开机的设备，例如家用服务器、NAS、路由器或树莓派。中心节点关机期间，离家同步会暂停，而在家的设备仍会继续直接同步。

选择你需要哪种中心节点：

- **读取副本的中心节点**：你群组的**主设备**（如果是电脑）或一台**管理员**电脑。设备会像对待其他读取设备一样为它封装副本，群组的[密钥级别](keys.md#the-three-levels)也适用于它的密钥。
- **只转发副本的中心节点**：群组中的任何普通电脑或小型开发板。设备会绕过它进行端到端封装，因此它不读取任何副本、不自行生成副本、不接受远程粘贴或快捷操作，也不需要硬件安全芯片。只有群组的主设备可以指定只转发副本的中心节点。

一个群组可以按优先级顺序设置多个中心节点；同一时间只有优先级最高的在线中心节点提供服务。要从主设备（或可担任中心节点的管理员电脑）设置优先级顺序，请运行 `sudo cbb global hubs NAME...`。

## 2. 在中心节点上开启

你可以通过桌面应用、管理员手机或终端来设置中心节点。

### 使用 Mac 应用或托盘应用

1. 在你想用作中心节点的电脑上打开 **CBB**。
2. 打开这台电脑自己的设备页，点按**设为中心节点**。
3. 如有提示，选择**读取副本的中心节点**或**只转发副本的中心节点**，并确认开启离家同步。

**结果**：应用会为这台电脑开启离家同步，并通过项目在 `cbb.tools` 的转发器将其配置为中心节点，因此你无需在路由器上开放端口。

### 使用管理员手机

1. 先在你想设为中心节点的电脑上开启离家同步（运行 `sudo cbb global on`，或在桌面应用中开启**随处**）。
2. 在手机上打开 **CBB**，在**主页**上点按这台电脑。
3. 如果这台电脑还不是管理员（且你希望它是读取副本的中心节点），请点按**设为管理员**并确认。
4. 点按**设为中心节点**，并使用面容、指纹、密码或（在 Aurora OS 上）你的管理员 PIN 确认。

**结果**：这台电脑会通过项目在 `cbb.tools` 的转发器成为中心节点。

### 使用终端

在 Linux、macOS 或 FreeBSD 上，在中心节点电脑上运行以下命令（在 Windows 上省略 `sudo`，改用管理员终端）：

1. 开启离家同步：

   ```sh
   sudo cbb global on
   ```

   如果这台电脑把密钥保存在文件中，请阅读提示并输入 `yes`。

   **结果**：服务会允许向你群组的服务器发起出站隧道连接，并保持其他所有互联网目标处于阻止状态。

2. 将电脑设为中心节点。选择以下方式之一：
   - **使用家庭公网地址直连**（IPv4、IPv6 或指向你家的域名）：

     ```sh
     sudo cbb global hub 203.0.113.7:8764
     ```

   - **通过转发器**（当你家没有公网地址，或你不想在路由器上开放端口时）：

     ```sh
     sudo cbb global hub
     ```

   **结果**：如果你提供了家庭地址，`cbb global hub` 会列出所需的 UDP 防火墙规则并在添加前询问你。如果不提供地址，中心节点会向项目在 `cbb.tools` 的转发器注册。

3. 如果你提供了家庭公网地址且中心节点位于路由器后面，请打开路由器设置，将 **UDP 端口 8764**（或你用 `-port` 指定的端口）转发到中心节点的局域网 IP 地址。在路由器设置中查找**端口转发**或**虚拟服务器**。

   如果将 **OpenWrt 路由器**用作中心节点，请以 `root` 身份不带 `sudo` 运行上述命令。除非路由器位于另一台路由器后面（双重 NAT），否则无需配置端口转发：当你确认防火墙提示后，Connect Beyond Borders 会把 WAN 的 UDP 规则添加到服务自己的防火墙规则中，而不会修改 `/etc/config/firewall`。

要从主设备（在命令行工具中称为 *root*）将另一台电脑设为只转发副本的中心节点，请先在那台电脑上开启离家同步，然后在主设备上运行：

```sh
sudo cbb global hub -on DEVICE -forward-only
```

## 3. 在其他设备上开启

当所有设备都在家庭网络中且中心节点正在运行时：

- **电脑和小型设备**：运行 `sudo cbb global on`（在 Windows 上，在管理员终端中不带 `sudo` 运行），或在 Mac 应用或托盘应用中开启**随处**。请注意，MIPS 路由器版本仅在家庭网络中同步；见[设备、端口和文件](../reference/devices.md)。
- **手机**：打开 **CBB**，在**主页**上开启**随处**（地球开关），然后在家中让应用保持打开片刻，以便与中心节点交换隧道密钥。Android 手机会在后台保持离家同步；iPhone、Aurora OS 和 HarmonyOS 手机会在应用打开时同步。

**结果**：每台设备都会收到中心节点的隧道邀约并与之交换隧道密钥。

## 4. 检查

1. 在每台电脑上运行：

   ```sh
   cbb global
   ```

   **结果**：输出会显示离家同步是否已开启、哪台设备是中心节点、隧道是否已连接，以及任何错误信息。

2. 让一部手机或一台笔记本离开家庭 Wi-Fi（例如把手机切换到移动数据），然后复制一行文本。

   **结果**：复制的文本会到达你家中的设备。

如果隧道未能连接，请检查路由器的 UDP 端口转发和公网地址，或见[故障排除：离家同步](troubleshooting.md#sync-away-from-home)。

如果之后你家的公网地址发生变化，中心节点会在设备下次相遇时共享新地址。当 `cbb global` 或 `cbb status` 报告系统的出站网络规则滞后时，在该电脑上运行 `sudo cbb global allow` 更新规则。

## 5. 当互联网无法访问你家时：转发器

许多互联网服务商将家庭网络置于运营商级 NAT（共享公网 IP 地址）之后，即使配置了端口转发也会阻止传入连接。**转发器**可以解决这个问题：你的中心节点向转发器发起传出连接，离家设备再通过它向中心节点发送加密的隧道数据包。路由器无需开放任何端口，转发器也不持有任何群组密钥。

在中心节点上选择以下两种方案之一：

- **使用项目在 `cbb.tools` 的转发器**：不带地址运行 `sudo cbb global hub`，或在中心节点自己的公网地址旁加上 `-forwarder default`：

  ```sh
  sudo cbb global hub -forwarder default 203.0.113.7:8764
  ```

- **使用你自己的转发器**：在任意拥有公网地址的服务器上运行转发器（[运行你自己的服务器](../admin/self-hosting.md#a-forwarder)），然后将它的地址和密钥传给中心节点：

  ```sh
  sudo cbb global hub -forwarder 198.51.100.9:8764 -forwarder-key KEY
  ```

**结果**：当中心节点同时配置了直连地址和转发器时，离家设备会先尝试直连地址，直连失败时再回退到转发器。

## 6. 屏蔽 VPN 的网络

酒店、办公室、移动运营商以及部分国家会屏蔽 WireGuard。默认情况下，中心节点会用 **AmneziaWG** 和（当所用转发器支持时）HTTPS 上的 **VLESS** 来伪装隧道。要配置或调整隧道伪装，见[屏蔽 VPN 的网络](blocked-networks.md)。

## 不在家的电脑：邀请

在通过中心节点的离家同步可用后，你可以邀请不在家庭网络中的电脑或手机加入。邀请只能使用一次，默认有效 1 小时（使用 `-for` 最长可设为 24 小时）。

### 邀请并接纳设备

1. 在主设备或管理员上创建邀请：
   - **在管理员电脑的终端中**：邀请电脑时运行 `sudo cbb invite`（生成 `cbb.cbbinvite`），邀请手机时运行 `sudo cbb invite -phone`（打印二维码）。在新设备加入前保持该命令运行。
   - **在手机或桌面应用中**：在**主页**点按 **+**（或在桌面应用中选择**添加设备 > 设备在远处？发送邀请**）并按提示操作。
2. 通过你信任的渠道将邀请文件、文本（`cbb://join#...`）或二维码发送给新设备。任何持有未使用邀请的人都可以申请加入，但你仍会通过核对密钥指纹来决定是否接纳。
3. 在新设备上使用邀请：
   - **在电脑上（终端）**：运行 `sudo cbb pair -invite cbb.cbbinvite`（或运行 `sudo cbb pair -invite -`，并在标准输入中粘贴 `cbb://join#...` 文本）。
   - **在电脑上（桌面应用）**：选择**通过邀请加入**并粘贴邀请文本。
   - **在手机上**：打开 **CBB**，点按**通过邀请加入**，然后扫描二维码、粘贴邀请文本或打开邀请文件。

   **结果**：两台设备都会显示新设备的密钥指纹。

4. 将邀请设备上显示的密钥指纹与新设备上显示的指纹进行比对。只有完全一致时，才输入 `yes`（或点按**接纳**）。

**结果**：新设备会加入你的群组，并开始通过中心节点同步。`cbb invite` 退出时会删除临时的邀请文件。

如需改用 SSH 或你自己的 VPN 从其他网络添加电脑，见[不用应用：从其他网络加入](without-app.md#joining-from-another-network)。

## 没有电脑可以担任中心节点

手机永远不能担任中心节点。如果你的群组里没有电脑、路由器或小型开发板来充当中心节点（例如仅由手机组成的群组），你的设备可以改为在**盲中继**上会合。两台设备必须同时在线才能交换副本。

盲中继无法读取你的剪贴板，但能看到哪些临时设备化名同时在线、它们的 IP 地址、时间以及流量大小。只有群组的**主设备**可以为群组开启或关闭盲中继，而且只有在你同意中继能看到的内容之后才能开启。

### 开启盲中继

- **在手机上（主设备）**：打开**设置**，开启**高级设置**，点按**盲中继**，选择项目的中继或输入你自己的中继地址和密钥，然后确认提示。
- **在电脑上（主设备）**：
  - 使用项目在 `cbb.tools:8765` 的开放中继：

    ```sh
    sudo cbb global relay default
    ```

  - 使用你自己的中继（[运行你自己的服务器](../admin/self-hosting.md#a-blind-relay)）：

    ```sh
    sudo cbb global relay 198.51.100.9:8764 -key KEY
    ```

  阅读中继能看到的内容后输入 `yes`。

**结果**：群组设置会指定该中继，开启了**随处**的设备会在那里会合。

要停止使用盲中继，请在主电脑上运行 `sudo cbb global relay off`，或在主手机上打开**设置 > 高级设置 > 盲中继**并点按**离开中继**。

## 关闭

### 停止让电脑担任中心节点

要让一台电脑不再担任中心节点，同时保持其离家同步处于开启状态：

- **在 Mac 应用或托盘应用中**：打开该中心节点的设备页，点按**不再作为中心节点**。
- **在终端中**：在中心节点上运行 `sudo cbb global hub off`，或在管理员电脑上运行 `sudo cbb global hub off -on NAME`。

**结果**：已连接的离家设备会自动切换到群组的下一个中心节点。如果群组没有其他中心节点，Connect Beyond Borders 会在停止前要求确认（在脚本中传入 `-yes` 以确认），因为在配置新的中心节点之前，离家设备会停止同步。

### 在某台设备上关闭离家同步

- **在电脑上**：运行 `sudo cbb global off`（在 Windows 上，在管理员终端中运行 `cbb global off`），或在桌面应用中关闭**随处**。
- **在手机上**：在**主页**上关闭**随处**。

**结果**：该设备会忘记自己的隧道密钥并停止离家同步。在 Linux 和 Windows 上，`cbb global off` 还会将群组的服务器从系统出站网络规则中移除。由于新的隧道密钥需要在家庭网络中与中心节点交换，在离家时关闭离家同步的设备，只有在回家重新连接后才能恢复离家同步。
