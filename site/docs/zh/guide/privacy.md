# 隐私：谁能看到什么

适合想知道哪些数据会离开自己设备、每台服务器和平台能观察到什么，以及如何限制或关闭每一项暴露的人。Connect Beyond Borders 没有账号、没有云端剪贴板存储，也没有分析遥测。

## 你的副本会经历什么

每一份副本——纯文本、机密内容、格式化文本、图片和文件——在离开你复制它的设备之前都会经过端到端加密：

1. 复制的设备会仅为这一份副本生成一把全新的 32 字节密钥，并用 ChaCha20-Poly1305 加密内容。
2. 它使用带 **X-Wing**（结合 X25519 和抗量子 ML-KEM-768）的 HPKE，为群组中每台读取副本的设备单独封装这把密钥，并用自己的成员密钥（ECDSA P-256）对副本签名。
3. 密封后的副本在使用群组设备密钥的双向 **TLS 1.3** 连接中传输，离家时还会进一步包在群组的 **WireGuard** 隧道中传输。

任何没有读取密钥的服务器、网络、互联网服务商或中间设备，都无法读取、篡改或伪造副本。被移除的设备不会收到之后的副本，新加入的设备也无法解密加入之前产生的副本。

## 中间的设备能看到什么

副本在到达目的地之前，可能会经过群组中的另一台设备——例如离家时经过你的中心节点，或在家中网络上经过另一位成员。只转发副本的设备无法拆开密封，因此它只能看到传递所需的信封元数据：

- **发送者与时间戳：**哪台设备在何时复制了该项目（用于判断哪份副本最新）。
- **接收者列表：**副本为哪些设备密封（群组成员通过群组的设备记录本来就知道这一点）。
- **取整后的大小：**文本负载大小按固定档位取整（`1`、`4`、`16`、`64`、`256` KB、`1` MB，之后按每 MB 一档），以及是否包含图片或文件附件，附件总大小取整到 `64` KB。同一份副本中的所有文件都在一个密封数据块内传输，因此文件数量是隐藏的。

中间设备绝不会知道副本是纯文本、机密内容、图片还是文件；绝不会看到文本或文件名；也绝不会看到精确的字节大小。

## 主动选择的例外情况

某些功能涉及 Connect Beyond Borders 端到端密封之外的通道。每一项都需要你明确选择：

- **Roku 电视遥控器（`cbb remote add -roku -consent`）：**Roku 的外部控制协议在你的家庭网络上使用未加密的 HTTP。不要向 Roku 发送密码（[键盘和电视](keyboards-and-tvs.md#a-computer-as-the-tvs-remote)）。
- **读取副本的中心节点：**担任中心节点的主设备或管理员电脑会像其他读取设备一样接收为它密封的副本。如果你的常开中心节点把密钥存放在文件中（例如树莓派或 NAS），请将它配置为**只转发副本的中心节点**，这样副本绝不会为它密封（[离家同步](away-from-home.md)）。带签名的命令（例如远程粘贴和快捷操作）始终只为其单一目标设备密封。
- **配对的手表（Apple Watch、Wear OS、HarmonyOS 手表）：**手表通过操作系统自有的加密手机-手表通道（WatchConnectivity、Wearable Data Layer 或 Wear Engine）与配对手机通信，只显示设备状态、事件和开关，而不是你的剪贴板内容。
- **蓝牙和 USB 键盘：**通过手机、Linux 电脑或 Arduino Nano ESP32 键盘输入的文本，会经由蓝牙或 USB 直接传送到已配对的目标设备。

## 群组之外的所有人

当离家同步关闭时，后台服务只在你的家庭网络中通信。当离家同步开启时，服务只与你的家庭网络以及群组自己的中心节点、转发器和中继通信（在每个操作系统上由代码强制执行，在 Linux 和 Windows 上还由系统防火墙/沙盒规则强制执行）。

转发器和盲中继都绝不会看到你的群组设备列表、设备名称或永久设备 ID。相反，你的群组会为每台服务器生成各自独立的临时**服务器凭据**，并每 30 天（以及在移除设备时）轮换一次，因此两台服务器无法把你群组的流量关联起来。

下表列出了群组之外可能观察到任何流量或元数据的每一方：

| 相关方 | 他们能看到什么 | 如何避免或限制 |
|---|---|---|
| **家庭网络上的其他设备** | mDNS 广播，显示有设备在运行 Connect Beyond Borders，以及它们的随机设备 ID、群组标签和端口；哪些本地 IP 地址在连接以及传输了多少数据。绝不会看到设备名称或剪贴板内容 | 电脑只在已知的家庭网络上广播，在不熟悉的 Wi-Fi 上保持静默 |
| **离家时所在的网络**（咖啡馆、酒店、移动运营商、ISP） | 加密的 WireGuard/AmneziaWG UDP 数据包——或使用 VLESS 时，连向转发器域名的 HTTPS 连接（在 TLS SNI 中可见）——以及时间和流量大小 | 在你的设备上运行系统 VPN，以隐藏目的地和时间信息 |
| **转发器**（项目在 `cbb.tools` 上的，或你自己的） | 与你的中心节点交换加密 WireGuard 数据包的 IP 地址、数据包时间和大小；仅可见轮换的服务器凭据标签，绝不会看到设备名称、群组成员或剪贴板内容 | 直接将 UDP 8764 端口转发到你的中心节点以不使用转发器，或[运行你自己的转发器](../admin/self-hosting.md#a-forwarder) |
| **盲中继**（项目在 `cbb.tools` 上的，或你自己的） | 同时在线的轮换设备化名、它们的 IP 地址、哪些化名在互相通信、时间和流量大小（仅保存在内存中，绝不写入日志）。绝不会看到剪贴板内容或设备名称 | 使用你自己的中心节点代替盲中继，或[运行你自己的中继](../admin/self-hosting.md#a-blind-relay) |
| **转发器或中继的托管服务商** | 连接到服务器的 IP 地址、连接时间和流量大小 | 在你的设备上使用系统 VPN，或在你自己选择的服务商处自托管 |
| **项目推送服务**（`cbb.tools`） | 在唤醒已关闭的手机应用时，看到手机的推送令牌、轮换的群组外观标签、发送者 IP 地址和通知时间戳。每条推送正文都为该手机密封并填充到固定大小，因此服务无法读取它 | 在手机**设置**中关闭**应用关闭时通知我** |
| **手机推送平台**（Apple APNs、Google FCM，或你的 UnifiedPush 分发器如 ntfy） | 有一条推送通知在何时发往你手机上的 Connect Beyond Borders；绝不会看到密封内容 | 在手机**设置**中关闭**应用关闭时通知我**，或在 Android 上使用 F-Droid 构建搭配你自己的 UnifiedPush 服务器代替 Google FCM |
| **更新服务器**（GitHub Releases、`raw.githubusercontent.com`、`dl.cbb.tools`，以及用于 OpenWrt 源的 `cbb.tools/openwrt`） | 你的 IP 地址，以及你检查或下载了 Connect Beyond Borders 的发布版本；不涉及任何关于你群组或副本的信息 | 关闭自动更新（`sudo cbb update -auto off`，或在 Android 的**设置 > 关于**中关闭），或将更新指向你自己的 HTTPS 镜像（`sudo cbb update -mirror https://...`） |
| **项目签名列表与认证镜像**（`cbb.tools`） | 获取带签名的服务器入口列表时，或主设备每日获取 Google 的 Android 认证吊销列表签名副本（`https://cbb.tools/attest/`）时的 IP 地址 | 向所有人提供的是相同的公开文件；通过镜像获取可避免直接联系 Google |
| **项目错误报告接收器**（`https://bug.cbb.tools/`） | 在此版本中看不到任何信息：应用目前还不会发送错误报告，因为用于密封报告的密钥不在构建中。加入密钥后，报告也只会在发生崩溃**且**你点击**允许**（或**始终允许**）后发送：你的 IP 地址、应用版本、崩溃指纹，以及一份为维护者的机器人密封的报告，包含经过过滤的错误日志、版本和设备型号，绝不包含剪贴板文本、文件、密钥、配对码、设备名称或 IP 地址 | 在崩溃提示上点按**取消**；未经你的同意不会发送任何内容 |
| **应用商店和包管理器**（Apple App Store / TestFlight、Google Play、F-Droid、Homebrew、winget） | 你安装或更新了 Connect Beyond Borders，与从该商店安装任何应用一样 | 直接从 GitHub Releases 安装带签名的发布归档或 APK |
| **网站统计**（`cbb.tools`） | 你在网页浏览器中浏览 `cbb.tools` 时的页面访问量，由自托管的 GoatCounter 实例统计，不使用 cookie，也不与第三方共享 | 应用和后台服务从不加载网站页面或统计代码 |

日志只保存在每台设备本地。启用错误详情（`CBB_DEBUG=1` 或应用设置中的**显示错误详情**）只会在本地记录底层错误详情，绝不会自动发送到任何地方。
