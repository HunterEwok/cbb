# 隐私：谁能看到什么

写给想知道哪些内容会离开自己设备的人。Copy Beyond Borders 没有账号、没有云端、没有遥测：你复制的内容经过端到端加密，在复制它的设备上为你群组中读取复制内容的设备封装，其他任何东西都无法打开它：服务器、网络、中间的设备都不能。本页说明传递复制内容的设备仍能看到什么，以及群组之外的人能看到的一切，和如何关闭。

## 你复制的内容

文字、图片和文件都经过端到端加密。复制的设备用一把只为这份复制内容生成的密钥加密它，再为群组中每台读取复制内容的设备封装这把密钥（X-Wing，结合 X25519 与抗量子的 ML-KEM-768），并用自己的成员密钥签名。只有这些设备能打开它；每台设备都会验证签名，因此没有人能修改复制内容，也不能冒用别人的名义制造一份。封装后的复制内容随后在使用群组自有证书的 TLS 1.3 中传输，离家时还会在 WireGuard 中传输，经过你的中枢，可能还经过转发器或中继。任何服务器、网络或服务商都无法读取它，包括本项目的服务器。被移出群组的设备不会再收到任何内容；新加入群组的设备从下一份复制内容开始读取，读不到加入之前的复制内容。

## 中间的设备能看到什么

复制内容常常经由另一台设备到达：离家时经由中枢，在家时经由转发它的电脑。这些设备读不到任何不是为它们封装的复制内容，但传递需要少量信息，这些留在封装之外：

- **由哪台设备发出，以及何时发出。** 时间用来决定哪份复制内容最新，每台设备都需要它，只转发复制内容的中枢也不例外。
- **为哪些设备封装。** 这就是群组的设备列表，它们本来就知道。
- **按档位计的大小**（1、4、16、64 和 256 KB、1 MB，之后每增加一 MB 一档），以及是否带有图片或文件，其总大小精确到 64 KB。一份复制内容的所有文件是一个封装块，所以文件数量不可见。

永远看不到的：它是文字、机密、图片还是文件；文字本身；文件名；确切大小。

## 例外

两者都由你选择：

- 用 `cbb remote add -roku -consent` 添加的 **Roku**，会在你的家庭网络中以明文 HTTP 收到文本（[键盘与电视](keyboards-and-tvs.md#a-computer-as-the-tvs-remote)）。
- **读取复制内容的中枢** 是你选定的管理员，因此复制内容像为你的其他设备一样为它封装。对于密钥只存放在文件中的常开电脑，例如 Raspberry Pi，请改为把它设为 **只转发复制内容的中枢**：不为它封装任何复制内容，所以它一份也读不到（[离家时](away-from-home.md)）。无论哪种情况，远程粘贴或快捷操作等命令都只为目标设备封装（[远程粘贴](remote-paste.md)）。
- **Apple Watch** 或 **Wear OS** 手表通过系统在手表与手机之间加密的通道从手机获得复制内容，而不是由 Copy Beyond Borders 封装。

## 其他所有人

| 谁 | 能看到什么 | 如何避免 |
|---|---|---|
| 你家庭网络中的其他人 | 那里有设备在运行 Copy Beyond Borders、它们的随机设备 ID 和 mDNS 中你群组的标签，以及哪些设备在通信、通信量多少；绝不会看到设备名称或内容 | 无需操作；电脑只在它所认识的家庭网络上发布信息（轻量成员则在每个网络上都发布） |
| 离家时所在网络中的其他人（咖啡馆、酒店） | 该设备在使用 WireGuard，或在使用 VLESS 时它向你的中枢或转发器建立了 TLS 连接，以及时间和通信量 | 系统级 VPN 可以连这些也隐藏 |
| 转发器（你自己的，或项目在 `cbb.tools` 的） | 加密数据包来自哪些地址、发往你的中枢的地址、时间和大小；看不出它们属于哪个群组或设备 | 运行自己的转发器，或者把一个端口转发到你的中枢而不使用转发器 |
| 盲中继 | 一个群组中哪些设备当前在线并相互通信，以及时间和通信量；它不保存其中任何内容 | 运行自己的中继，或使用中枢 |
| 托管转发器或中继的公司 | 与它通信的地址、时间和通信量 | 在设备上使用系统级 VPN |
| GitHub，或 GitHub 无响应时的 `dl.cbb.tools` | 每次检查更新和下载时，你的地址以及你在使用 Copy Beyond Borders；不涉及任何群组信息 | `sudo cbb update -auto off`，或使用你自己的镜像（`-mirror`） |
| `cbb.tools` | 根每天一次获取 Google 已吊销 Android 密钥列表的签名副本时的根地址（该副本开始提供之后，使用项目的签名密钥） | 无需处理：这对所有人都是同一个文件 |
| Apple、Intel 或 AMD | 这类设备曾从你的地址请求它们为其密钥作保 | 只有在**严格**密钥级别才会这样；默认级别不会询问任何一方（[密钥](keys.md#the-three-levels)） |
| App Store、Google Play、F-Droid、Homebrew、winget | 你安装了这个应用，与任何应用一样 | 改为安装发布页上带签名的文件 |

没有任何东西会上报崩溃或使用情况。日志只留在各台设备上；开启错误详情（`CBB_DEBUG=1`）后，日志会记录更多原因，仍然只在那台设备上。

## 网站

`cbb.tools` 用它自己的 GoatCounter 统计访问量，不使用 cookie，也不会向其他公司发送任何信息。除上述文件外，应用和服务从不会从它加载任何东西。
