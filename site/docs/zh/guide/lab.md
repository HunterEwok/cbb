# 实验室

Copy Beyond Borders 只承诺一件事：为你的手机和电脑提供一个加密的剪贴板。实验室是它尝试你的一组设备还能做些什么的地方。这里的一切都能用，并且在 CI 中经过测试，但它们是实验，不是 1.0 的承诺：可能会改变，其中一些还没有在真实硬件上运行过。

| 实验 | 作用 | 位置 |
|---|---|---|
| 键盘 | Android 手机、Linux 电脑或 Nano ESP32 向电视、平板、游戏机或没有装任何 Copy Beyond Borders 的电脑输入文字 | [键盘和电视](keyboards-and-tvs.md) |
| 电视遥控器 | 家里的一台电脑作为 Android TV、Google TV 或 Roku 的遥控器向其输入文字 | [键盘和电视](keyboards-and-tvs.md#a-computer-as-the-tvs-remote) |
| Arduino Nano ESP32 | 一块几欧元的板子作为你群组中的设备，它的 USB 接口作为键盘 | [固件](../../esp32/README.md) |
| ZX Spectrum Next | Next 通过它内部的 Raspberry Pi 复制到群组并从群组粘贴 | [Next 的 `.cbb`](../../apps/zxnext/README.md) |

请在 issue 中告诉我们某个实验在你那里效果如何。证明自己有价值的实验可能会走出实验室，成为 Copy Beyond Borders 承诺的一部分。
