# 设备丢失或被盗时

适用于群组中的手机、电脑或其他设备丢失的人。请尽快把它从群组中移除；其他设备仍留在群组中，继续同步。

## 1. 移除它

在作为管理员的手机上，在**主页**点按丢失的设备，再点 **Remove**。在管理员电脑上：

```sh
sudo cbb remove NAME     # NAME, or the device ID, as cbb status shows it
```

群组中的每台设备都会得知此事，并停止与丢失的设备通信。只有根或管理员手机才能移除管理员。

## 2. 如果它是管理员电脑：先冻结它

管理员电脑的密钥可以签名。如果它可能落入他人之手，请在任意管理员上冻结它，这样它此后签署的一切都不再生效，然后再移除它：

```sh
sudo cbb freeze NAME
```

被冻结的管理员无法冻结根或管理员手机。如果它反过来冻结对方，则双方都保持冻结，直到根做出决定（在根上运行 `cbb unfreeze` 或 `cbb remove`，或在根手机上点 **Unfreeze** 和 **Remove**）。

## 3. 如果它是根：接管群组

根保管着群组的根密钥。它丢失之后，由一个管理员成为新的根，其他所有设备仍留在群组中：

- 使用手机时：在作为管理员的另一部手机上，移除丢失的那一部；应用会在同一步中接管群组；
- 使用电脑时：在管理员电脑上运行 `sudo cbb takeover NAME`，其中 NAME 是丢失的根。

如果别人拿到了一台被移除的管理员设备，他们可以签署自己的接管请求，让群组暂停一段时间：各设备会显示群组已暂停。这时由旧的根来结束暂停（如果你还有它）；在 0.6 中新的根做不到，如果旧的根也丢了，就需要重新建立群组（[协议](../protocol.md)，第 10 节，“Known limits in 0.6”）。

如果群组中没有其他管理员，就无法接管：请新建一个群组，并重新添加设备。这正是应用在群组只有一个管理员时，就建议你再添加第二部管理员手机或一台管理员电脑的原因。

## 4. 关闭它能触及的功能

对群组来说，移除设备就够了。如果你暂时还不能移除它，或想确保其他设备的安全，管理员还可以远程关闭：

| 内容 | 在管理员电脑上的命令 |
|---|---|
| 某台设备或所有设备上的[远程粘贴](remote-paste.md) | `cbb paste-receive off -on DEVICE`、`-all` |
| 某台设备或所有设备上的[快捷操作](quick-actions.md) | `cbb action off -on DEVICE`、`-all` |
| 某台设备上的离家同步 | `cbb global off -on DEVICE` |

管理员手机在设备页面提供同样的操作，管理员手表也可以发送这些指令。只有各设备自己的用户才能重新开启它们。

## 小偷能得到什么

这取决于设备把密钥存放在哪里（[密钥与证明](keys.md)）：

- **密钥在硬件中**（手机、带 Secure Enclave 的 Mac、带 TPM 的电脑）：没有可复制的东西。密钥只能在那台设备上签名，而手机的根密钥和管理员密钥只有在验证你的面容、指纹或密码之后才会签名。
- **密钥在文件中**（没有 T2 芯片的 Intel Mac，以及没有 TPM 的 Windows 电脑和 Linux 电脑、小设备）：任何复制了该文件的人，在你移除它之前都能冒充这台设备。请加密磁盘（FileVault、BitLocker、LUKS），这样被盗的设备不会泄露任何东西。

设备上不保存剪贴板历史，机密内容在复制 60 秒之后就会消失。
