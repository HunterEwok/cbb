# 如果设备丢失或被盗

适合群组中的手机、电脑或其他设备丢失或被盗的人。在本页中，你将了解如何移除丢失的设备、冻结被盗的管理员电脑、在主设备丢失时把群组移到新的主设备，以及关闭其余设备上的远程功能。

一旦发现设备丢失，请尽快将其移除。你其余的设备仍留在群组中，无需重新配对即可继续同步。

## 1. 移除丢失的设备

移除设备会广播一条带签名的移除记录，使其他每台设备都拒绝来自它的连接，并不再为它密封副本。只有**主设备**（在命令行工具中称为 *root*）或**管理员手机**可以移除另一位管理员；管理员电脑只能移除普通成员。

- **在主设备或管理员手机上：**
  1. 打开 **CBB**，在**主页**上点按丢失的设备。
  2. 点按**移除**，并用你的面容、指纹、密码或（在 Aurora OS 上）管理员 PIN 确认。
- **在主设备或管理员电脑上（终端）：**

  ```sh
  sudo cbb remove NAME
  ```

  将 `NAME` 替换为 `cbb status` 中显示的设备名称或设备 ID（在 Windows 的管理员终端中省略 `sudo`）。
- **在 Mac 应用或托盘应用中（主设备或管理员）：**打开丢失设备的详情面板，点击**移除**并确认。

**结果：**每台已连接的设备会立即拒绝被移除的设备，离线设备则在重新连接后立即拒绝它。被移除的设备只能作为新设备重新配对后才能再次加入。

## 2. 如果是管理员电脑：先冻结它

管理员电脑可以签署群组变更并发送命令。如果一台管理员电脑可能落入他人之手，而你手边没有主设备或管理员手机来移除它，请先从任意管理员设备上将其冻结。

1. 在任意管理员设备上执行：
   - **终端：**`sudo cbb freeze NAME`
   - **手机或桌面应用：**在**主页**上打开该管理员电脑，选择**冻结**并确认。

   **结果：**从那时起，被冻结的管理员签署的任何内容都不再生效，其他每台设备都会拒绝它的连接。被冻结的管理员无法冻结主设备或管理员手机。

2. 一旦拿到主设备或管理员手机，请立即移除被冻结的电脑（第 1 步）。

如果两台管理员电脑在得知对方冻结自己之前互相冻结了对方，两台设备都会保持冻结状态，直到主设备做出决定：在主电脑上运行 `sudo cbb unfreeze NAME` 或 `sudo cbb remove NAME`，或在主手机上选择**解冻**或**移除**。

## 3. 如果是主设备：把群组移到另一台设备

**主设备**持有群组的主密钥。如果主设备丢失或损坏，请使用群组的**恢复密钥**（创建群组时保存的打印恢复单或 YubiKey），将群组移到已在群组中的另一台设备。

没有恢复密钥，任何人都无法把群组移到其他设备，管理员也不行。如果你没有恢复密钥，就无法移动群组：请在其余每台设备上退出旧群组（运行 `sudo cbb leave` 或在应用中选择**离开群组**），新建一个群组，然后重新配对你的设备。

### 把群组移到群组中的手机

1. 在已在你群组中的另一部手机上，打开 **CBB**，前往**设置 > 把群组移到这部手机**。
2. 提供恢复密钥：
   - **恢复单：**扫描纸上的二维码，或输入其文字。
   - **YubiKey：**将 YubiKey 贴近手机（NFC）或插入 USB-C 接口（在 Aurora OS 上仅支持 USB-C），输入其 PIN，并在提示时触摸 YubiKey。
3. 查看群组中的设备列表，取消勾选丢失的主设备（以及任何你想排除的其他设备）。
4. 点按**把这部手机设为主设备**，并用你的面容、指纹、密码或（在 Aurora OS 上）管理员 PIN 确认。

**结果：**这部手机会立即使用新的主密钥成为群组的主设备。每台勾选的设备都留在群组中，并在一连接时跟随新主设备；每台未勾选的设备都会被排除并遭到群组拒绝。

### 把群组移到群组中的电脑

1. 在群组中的另一台电脑上，打开终端（在 Windows 上以管理员身份运行）并执行：
   - **使用恢复单：**

     ```sh
     sudo cbb recovery -leave LOST-DEVICE
     ```

   - **使用 YubiKey**（在 Linux 和 FreeBSD 上需要 `pcscd`）：

     ```sh
     sudo cbb recovery -yubikey -leave LOST-DEVICE
     ```

   要排除多台设备时，可为每台设备重复使用 `-leave NAME`。你也可以在 Mac 应用或托盘应用中通过**把群组移到这台 Mac** / **把群组移到这台电脑**启动这一流程。
2. 核对哪些设备留下、哪些离开并确认，然后通过标准输入键入恢复单上的恢复密钥（或输入 YubiKey 的 PIN 并在它闪烁时触摸它）。

**结果：**这台电脑的服务会作为群组的新主设备重启，保留列出的每台设备，并拒绝被排除的每台设备。更换完成后，这台电脑会丢弃恢复密钥。

## 4. 如有需要，关闭远程功能

移除丢失的设备即可阻止它在你的群组中继续活动。如果你无法立即移除它，或者想立刻锁定你其余的设备，任何管理员都可以从另一台设备关闭以下功能：

| 功能 | 在管理员电脑上的命令 | 在管理员手机应用中 |
|---|---|---|
| [远程粘贴](remote-paste.md) | `sudo cbb paste-receive off -on DEVICE`（或 `-all`） | 打开设备页面并关闭远程粘贴 |
| [快捷操作](quick-actions.md) | `sudo cbb action off -on DEVICE`（或 `-all`） | 打开设备页面并点按**全部关闭** |
| [离家同步](away-from-home.md) | `sudo cbb global off -on DEVICE` | 打开设备页面并关闭离家同步 |

**结果：**受影响的设备会立即停用这些功能。只有每台设备自己的用户才能在本机重新开启它们。

## 小偷能接触到什么

偷走你设备的人能获取到什么，取决于该设备将密钥存放在哪里（见[密钥与认证](keys.md)）：

- **密钥在硬件中**（带安全芯片的手机、搭载 Apple 芯片或 T2 芯片的 Mac，以及带 TPM 2.0 的 Linux 或 Windows 电脑）：密钥无法从设备中复制出去。在手机上，主密钥和管理员密钥只有在验证你的面容、指纹、密码或（在 Aurora OS 上）管理员 PIN 后才会签名。
- **密钥在文件中**（没有 T2 芯片的 Intel Mac、没有 TPM 的 Linux 和 Windows 电脑、FreeBSD、小型设备、Aurora OS 4 和 Sailfish OS 手机，以及无 root 的 Linux 安装）：任何能读取磁盘的人都可以复制密钥文件并在你移除该设备前冒充它。请始终开启全盘加密（FileVault、BitLocker 或 LUKS）。

Connect Beyond Borders 不保存剪贴板历史。普通副本会在超过群组的副本保留时长（默认 5 分钟）后过期，机密内容只保存在内存中并默认在 60 秒后过期。
