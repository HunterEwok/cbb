# الإجراءات السريعة

لكل من يريد قفل حاسوب أو وضعه في السكون أو إعادة تشغيله أو إيقاف تشغيله أو تشغيل برنامج ثابت عليه من هاتف مشرف أو حاسوب مشرف آخر في المجموعة.

يشغّل **المشرف** إجراءً سريعًا بلمسة واحدة أو أمر واحد، ولا ينفّذه الحاسوب المستهدف إلا إذا كان مستخدم ذلك الحاسوب نفسه قد شغّل ذلك الإجراء محليًا. يبدأ كل إجراء سريع متوقفًا افتراضيًا، ولا يستطيع أحد تشغيل إجراء عن بُعد.

## الإجراءات المدمجة

| الإجراء | ما يفعله | الأجهزة المدعومة |
|---|---|---|
| `lock` | يقفل الشاشة | الحواسيب، والأجهزة الصغيرة |
| `sleep` | يضع الحاسوب في السكون | الحواسيب، والأجهزة الصغيرة |
| `reboot` | يعيد تشغيل الحاسوب بعد تحذير مدته دقيقة واحدة | الحواسيب، والأجهزة الصغيرة |
| `shutdown` | يوقف تشغيل الحاسوب بعد تحذير مدته دقيقة واحدة | الحواسيب، والأجهزة الصغيرة |
| `cancel-shutdown` | يلغي إعادة تشغيل أو إيقاف تشغيل معلّقًا | الحواسيب، والأجهزة الصغيرة |
| `restart` | يعيد تشغيل خدمة Connect Beyond Borders | الحواسيب، والأجهزة الصغيرة |
| `keyboard-layout` | يبدّل التخطيط النشط لـ [لوحة مفاتيح البلوتوث](keyboards-and-tvs.md) الخاصة بالحاسوب إلى التخطيط التالي | حواسيب Linux التي تعمل فيها لوحة مفاتيح البلوتوث |

تمنح مهلة دقيقة واحدة قبل `reboot` أو `shutdown` أي شخص يجلس أمام الحاسوب وقتًا لحفظ عمله أو تشغيل `cancel-shutdown`. وعلى Windows، يرى المستخدمون المسجّل دخولهم تحذيرًا من النظام أيضًا.

على macOS وWindows، تعمل إجراءات الجلسة (`lock` و`sleep` والإجراءات المخصّصة) عبر وكيل الحافظة الخاص بالمستخدم المسجّل دخوله، لذا يجب أن يكون هناك مستخدم مسجّل الدخول. وعلى macOS، يتطلب `lock` ضبط **إعدادات النظام > شاشة القفل > طلب كلمة السر بعد بدء شاشة التوقف أو إيقاف الشاشة** على **فورًا**.

## 1. شغّل إجراءً مدمجًا

شغّل هذه الأوامر على الحاسوب المستهدف (استخدم `sudo` على Linux وmacOS وFreeBSD؛ واستخدم طرفية المسؤول من دون `sudo` على Windows):

1. اعرض جميع الإجراءات واعرف من المسموح له بتشغيل كل منها:

   ```sh
   cbb action
   ```

2. فعّل إجراءً:

   ```sh
   sudo cbb action enable lock
   ```

   اقرأ ما يسمح به الإجراء واكتب `yes` (أو مرّر `-yes` في البرامج النصية).

   **النتيجة:** يعمل الإجراء لكل مشرف في مجموعتك. وعلى Linux، يكتب Connect Beyond Borders الملف `/etc/polkit-1/rules.d/60-cbb.rules` لمنح الخدمة صلاحيات polkit اللازمة للإجراءات المفعّلة فقط.

3. يمكنك اختياريًا تقييد المشرفين الذين يستطيعون تشغيل إجراء ما:
   - قيّد بحسب نوع الموقِّع باستخدام `-by` (`root` للجهاز الرئيسي، و`phone` لهواتف المشرفين، و`computer` لحواسيب المشرفين، و`watch` لساعة موقِّعة):

     ```sh
     sudo cbb action enable reboot -by root,phone
     ```

   - افتراضيًا، لا يقبل `reboot` و`shutdown` إلا المشرفين الذين تقيم مفاتيحهم في العتاد (هاتف، أو جهاز Mac بشريحة Secure Enclave، أو حاسوب بـ TPM 2.0). وللسماح للمشرفين الذين مفاتيحهم في ملفات أيضًا، أضف `-any-key`:

     ```sh
     sudo cbb action enable reboot -any-key
     ```

لإيقاف إجراء واحد مجددًا:

```sh
sudo cbb action disable lock
```

**النتيجة:** يتوقف الإجراء فورًا. وعلى Linux، يحدّث التعطيل قاعدة polkit أو يزيلها فتُسحب الصلاحيات غير المستخدمة.

## 2. أضف إجراءً خاصًا بك

يمكنك تعريف ما يصل إلى 32 إجراءً مخصّصًا لكل حاسوب (يجب أن يتكوّن الاسم من 1 إلى 32 حرفًا لاتينيًا صغيرًا أو أرقامًا أو شرطات، ويبدأ بحرف).

1. سجّل الأمر على الحاسوب المستهدف، مع ذكر البرنامج بمساره الكامل بعد `--`:

   ```sh
   sudo cbb action add backup -by phone -- /usr/local/bin/backup.sh --quick
   ```

2. اقرأ ملخّص ما يسمح به الإجراء واكتب `yes`.

**النتيجة:** يحفظ Connect Beyond Borders الأمر في إعدادات مستخدمك (`own-actions.json`) بحيث لا يستطيع سوى وكيل المستخدم المسجّل دخوله تشغيل ذلك الملف التنفيذي وقائمة الوسائط بالضبط من دون صدفة (shell). ولا يتلقى المُرسِل إلا حالة الخروج. يجب أن تنتهي الأوامر خلال 15 ثانية؛ ابدأ المهام الأطول في الخلفية.

لإزالة إجراء مخصّص:

```sh
sudo cbb action remove backup
```

## 3. شغّل إجراءً من جهاز مشرف

- **من حاسوب مشرف (الطرفية):**

  ```sh
  cbb action -on DEVICE NAME
  ```

  استبدل `DEVICE` باسم الجهاز المستهدف أو معرّفه من `cbb status`، و`NAME` باسم الإجراء.

  **النتيجة:** يطبع `cbb` ما إذا كان الإجراء قد نُفّذ أو سبب رفض الجهاز المستهدف له.

- **من هاتف مشرف:**
  1. افتح **CBB** واضغط الحاسوب المستهدف المتصل في **الرئيسية**.
  2. ضمن **إجراءات سريعة**، اضغط الإجراء الذي تريد تشغيله.
  3. أكّد بوجهك أو بصمتك أو رمز الدخول أو (على Aurora OS) برمز PIN للمشرف. يطلب `reboot` و`shutdown` تأكيدًا ثانيًا.

  **النتيجة:** يشغّل الجهاز المستهدف الإجراء ويعرض الهاتف **تم.**

## 4. أوقف جميع الإجراءات

- **محليًا على الحاسوب المستهدف:**

  ```sh
  sudo cbb action off
  ```

- **عن بُعد من أي حاسوب مشرف:**

  ```sh
  sudo cbb action off -on DEVICE     # one computer
  sudo cbb action off -all           # every computer in the group
  ```

- **عن بُعد من هاتف مشرف:** افتح صفحة الجهاز في **الرئيسية** واضغط **إيقاف الكل**.

**النتيجة:** تتوقف كل الإجراءات السريعة على الحواسيب المتأثرة فورًا. ولا يستطيع إعادة تشغيلها محليًا إلا مستخدم كل حاسوب نفسه.

يحتفظ كل حاسوب مستهدف بسجل تدقيق (`actions-log.json`) لآخر 100 طلب إجراء، يسجّل فيه من طلب كل إجراء ومتى. للاطلاع على الحدود الدقيقة، انظر [الحدود والمدد](../reference/limits.md#remote-paste-and-quick-actions).
