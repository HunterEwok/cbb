# من دون التطبيق

لمن يريد إنشاء مجموعة Connect Beyond Borders وإدارتها باستخدام الحواسيب فقط، من دون تطبيق هاتف. في هذه الصفحة، تنشئ مجموعة على حاسوب واحد، وتضيف حواسيب أخرى على شبكتك المنزلية، وتُعدّ مشرفًا ثانيًا، وتضيف حواسيب من شبكة أخرى عبر SSH أو VPN.

![حاسوب Linux يحمل المجموعة ويضيف Mac وWindows برمز من ستة أرقام](../images/without-app.svg)

الحاسوب الذي ينشئ مجموعة يصبح **جهازها الرئيسي** (يُسمّى *root* في أدوات سطر الأوامر والرسوم التوضيحية). لا يمكن [لتثبيت Linux بلا صلاحيات root](install.md#without-sudo-rootless) أن يكون أبدًا الجهاز الرئيسي أو مشرفًا، وتتطلب حاوية Docker وجود `CBB_KEYS_IN_FILE=yes` في بيئتها قبل الاحتفاظ بمفاتيح المجموعة.

## 1. أنشئ المجموعة على حاسوب

اختر حاسوبًا يعمل بانتظام (Linux أو macOS أو Windows أو FreeBSD) و[ثبّت Connect Beyond Borders](install.md).

1. شغّل على ذلك الحاسوب (احذف `sudo` في طرفية مسؤول على Windows، أو انقر **إنشاء مجموعة** في تطبيق Mac أو تطبيق شريط النظام):

   ```sh
   sudo cbb new
   ```

2. احفظ **ورقة الاسترداد** المعروضة على الشاشة—أربعة أسطر من الحروف والأرقام مع رمز QR. اطبعها أو دوّنها واحفظها بعيدًا عن أجهزتك.

**النتيجة:** يصبح هذا الحاسوب الجهاز الرئيسي للمجموعة. على جهاز Mac ذي شريحة Apple أو شريحة T2، أو حاسوب Linux أو Windows مزوّد بشريحة TPM 2.0، تُحفظ مفاتيحه في عتاد الأمان؛ وإلا فتُحفظ في ملفات محمية (يبدأ `cbb keys` عند `files`؛ انظر [المفاتيح والتصديق](keys.md)). لا يحتفظ أي شيء بنسخة من ورقة الاسترداد—فهي الطريقة الوحيدة لنقل المجموعة إذا فُقد هذا الحاسوب.

## 2. أضف حواسيب على شبكتك المنزلية

ثبّت Connect Beyond Borders على كل حاسوب إضافي على الشبكة المنزلية نفسها، ثم اقرنه:

1. على الجهاز الرئيسي (أو أي حاسوب مشرف)، افتح نافذة اقتران:

   ```sh
   sudo cbb pair
   ```

   **النتيجة:** تعرض الطرفية رمز اقتران من 6 أرقام ورمز QR، وتنتظر لمدة 5 دقائق. يمكنك أيضًا فتح نافذة اقتران من الزر **+** في تطبيق Mac أو تطبيق شريط النظام.

2. على الحاسوب الجديد، انضم إلى المجموعة:
   - **الطرفية:** شغّل `sudo cbb pair -code` (احذف `sudo` في طرفية مسؤول على Windows) واكتب الأرقام الستة عندما يُطلب منك ذلك.
   - **تطبيق سطح المكتب:** افتح **CBB**، واختر **الانضمام إلى مجموعة**، واكتب الأرقام الستة.

   يستهلك كل رمز خاطئ محاولة من 3 محاولات؛ وتُغلق النافذة بعد 3 محاولات فاشلة أو بمجرد انضمام جهاز.

**النتيجة:** يؤكد كلا الحاسوبين الانضمام، وتتزامن حافظتاهما تلقائيًا. انسخ نصًا على أحد الحاسوبين والصقه على الآخر للتحقق (انظر [البدء السريع: انسخ على جهاز والصق على آخر](quickstart.md#4-copy-on-one-paste-on-another)).

## 3. أضف مشرفًا ثانيًا واحفظ ورقة الاسترداد بأمان

رقِّ حاسوبًا ثانيًا ليصبح **مشرفًا** حتى يظل بإمكانك إضافة الأجهزة وإزالتها عندما يكون الجهاز الرئيسي غير متصل. لاحظ أنه لا يمكن ترقية حاسوب إلى مشرف إلا إذا كان قد اقترن مباشرةً مع الجهاز الرئيسي.

1. ابحث عن اسم الحاسوب أو معرّف الجهاز باستخدام `cbb status`.
2. على الجهاز الرئيسي، رقِّ الحاسوب:
   - **حاسوب مزوّد بشريحة TPM 2.0 أو Secure Enclave:**

     ```sh
     sudo cbb admin NAME
     ```

   - **حاسوب تُحفظ مفاتيحه في ملفات** (يتطلب مستوى المفاتيح `files`، ويُضبط باستخدام `sudo cbb keys files`):

     ```sh
     sudo cbb admin -allow-file-key NAME
     ```

     أي شخص ينسخ ملفات مفاتيح مشرف ذي مفاتيح في ملف يمكنه التصرف كمشرف حتى يزيل مشرف آخر ذلك الحاسوب، لذا لا ترقِّ إلا حواسيب تحافظ على أمانها المادي وتشفر أقراصها.

**النتيجة:** يدرج `cbb status` الحاسوب الثاني كمشرف، ويستطيع تشغيل `sudo cbb pair` و`sudo cbb remove NAME` للأعضاء العاديين.

إذا فُقد الجهاز الرئيسي أو تعطل يومًا، فانقل المجموعة إلى حاسوب آخر في المجموعة باستخدام ورقة الاسترداد:

```sh
sudo cbb recovery -leave LOST-DEVICE
```

ثم اكتب مفتاح الاسترداد من الورقة عندما يُطلب منك ذلك (أو مرّر `-yubikey` إذا كنت قد ختمته على YubiKey). انظر [إذا فُقد جهاز أو سُرق](lost-device.md) للاطلاع على الإجراء الكامل.

## الانضمام من شبكة أخرى

لإضافة حاسوب ليس على شبكتك المنزلية، يمكنك إرسال [دعوة عبر محور](away-from-home.md#a-computer-that-is-not-at-home-an-invitation)، أو الاقتران عبر نفق SSH أو عبر شبكة VPN الخاصة بك.

### عبر SSH

1. على الحاسوب الجديد، حوّل منفذًا محليًا إلى منفذ العضو على الجهاز الرئيسي أو المشرف (8764 افتراضيًا):

   ```sh
   ssh -N -L 18764:localhost:8764 user@admin-machine
   ```

2. في جلسة SSH منفصلة على الجهاز الرئيسي أو الحاسوب المشرف، افتح نافذة اقتران:

   ```sh
   sudo cbb pair
   ```

   انسخ السطر الكامل `cbb://pair?...` المطبوع تحت الأرقام الستة. (من دون اكتشاف الشبكة المحلية، لا تستطيع الأرقام الستة وحدها تحديد النافذة؛ إذ يحمل سطر `cbb://pair?...` تفاصيل النافذة والرمز معًا.)

3. على الحاسوب الجديد، انضم عبر المنفذ المحوَّل والصق سطر `cbb://pair?...` عندما يُطلب منك ذلك:

   ```sh
   sudo cbb pair -code 127.0.0.1:18764
   ```

**النتيجة:** ينضم الحاسوب الجديد إلى المجموعة عبر نفق SSH داخل TLS 1.3.

### عبر شبكة VPN الخاصة بك

1. على Linux، إذا أعددت VPN بعد تثبيت Connect Beyond Borders، فأعد تشغيل المثبّت حتى تسمح قواعد جدار الحماية بشبكة VPN الفرعية لديك.
2. على الجهاز الرئيسي أو الحاسوب المشرف، شغّل `sudo cbb pair` وانسخ سطر `cbb://pair?...` المطبوع تحت الأرقام الستة.
3. على الحاسوب الجديد، انضم باستخدام عنوان VPN ومنفذ الحاسوب المشرف، والصق سطر `cbb://pair?...` عندما يُطلب منك ذلك:

   ```sh
   sudo cbb pair -code ADMIN-VPN-ADDRESS:8764
   ```

**النتيجة:** ينضم الحاسوب الجديد إلى مجموعتك عبر VPN داخل TLS 1.3.

لا ينتقل سرّ الاقتران أبدًا بنص واضح: يشتق كلا الحاسوبين إثبات الجلسة داخل TLS 1.3. ويستمر الحاسوب الجديد في المزامنة عبر مسار الاقتران المؤقت حتى تُعاد تشغيل خدمته؛ ولمواصلة المزامنة بصورة دائمة بعد إغلاق SSH أو شبكة VPN الخاصة بك، أعدّ [المزامنة خارج المنزل](away-from-home.md) على كلا الجهازين أولًا.
